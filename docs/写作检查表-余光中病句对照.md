# 写作检查表：余光中《中文的常态与变态》病句对照

> 用途：AI 写完中文稿后的自查表。左边是「西化中文」的典型写法，右边是余光中给的自然说法。
> 原文出处：余光中《中文的常态与变态》（又题《怎样改进英式中文？——论中文的常态与变态》），《明报月刊》1987 年 10 月号；收入《余光中谈翻译》（中国对外翻译出版公司，2002）、《翻译乃大道》、《中和西》（2006，九篇合集）。
> 整理日期：2026-11-03。原句按原文摘录，个别明显笔误（如「推行的国语」）按上下文校正。

## 怎么用

**按节对照，不只搜关键词。** 这几类病大多不靠固定的词，搜词搜不出来（2026-11-03 拿第 3 章试过：关键词几乎没命中，按句式逐句对照查出 4 处）。

1. **逐句对照这五节**（技术稿最常犯）：
   - 第二节：一件事被压成名词词组。如「成功的大输出」→「命令成功、输出又很长时」。
   - 第四节：给平实的话套学术外壳。如「可扩展性」「难度很高」。
   - 第十节：一句里「的」太多。数到三个以上，先拆句。
   - 第十一节：长修饰语堆在名词前。改成后饰，先说名词，再一路补充。
   - 第十二节：被动语气。「会被丢掉」→「就丢了」；能补出谁做的，就写成主动。
2. **第一、三节顺手看**：套话（「基于这个原因」）、弱动词（「进行」「作出」「造成」）。弱动词搜得出来，附录 A 的关键词就够。
3. **第五、六、七、八、九节搜关键词就够**：们、之一、及、有关 / 关于 / 由于、成功地。用附录 A 的正则过一遍。
4. **命中不等于要改。** 每一处问一句：删掉或改掉，意思有没有损失？没有就改；有，才保留。
5. **一句里有几种病，先拆句**，再逐句处理。

这份表只管句子内部的西化中文，管不到句与句之间的衔接（转折突兀、先用后讲、数字主线断、省主语）。那一类按 `docs/第四版重构指南.md` 3.3 第 9–13 条查。

## 一、化简为繁：套话代替短词

| 原句（病） | 改成 | 病灶 |
|---|---|---|
| 基于这个原因 | 因此 | 四字换两字，只为显得正式 |
| 有很多问题存在 | 问题很多 | 「存在」是凑字 |
| 不是一句话就能够说得清楚的 | 一言难尽 | 成语被绕成了长句 |
| 总的来说 | 总而言之 | 同上 |

## 二、抽象名词作主语或受词

中文习惯拿**具体的东西**（尤其是人）或**一件事**作主语；英文习惯拿抽象名词作主语，再配一个泛动词。

| 原句（病） | 改成 | 病灶 |
|---|---|---|
| 他的收入的减少改变了他的生活方式 | 他因为收入减少而改变生活方式 | 抽象名词「减少」当主语 |
| 横贯公路的再度坍方，是今日的头条新闻 | 横贯公路再度坍方，是今日头条新闻 | 一件事被压成名词词组 |
| 书籍的选购，只好委托你了 | 选购书籍，只好委托你了 | 动词被名词化 |
| 国语的推行，要靠大家的努力 | 推行国语，要靠大家努力 | 同上，还多一个「的」 |
| 他们杯葛这种风俗的继续 | 他们反对保存这种风俗 | 受词位置塞了抽象名词 |

## 三、弱动词：万能动词 + 抽象名词

「作出」「进行」这类词把原本一个动词劈成两半：一半变静止的名词，一半变没表情的动词。余光中说这两个词「几乎要吃掉一半的正规动词」。

| 原句（病） | 改成 | 病灶 |
|---|---|---|
| 本校的校友对社会作出了重大的贡献 | 本校的校友对社会贡献很大 | 作出 + 贡献 |
| 昨晚的听众对访问教授作出了十分热烈的反应 | 昨晚的听众对访问教授反应十分热烈 | 作出 + 反应 |
| 我们对国际贸易的问题已经进行了详细的研究 | 我们对国际贸易的问题已经详加研究 | 进行 + 研究 |
| 心理学家在老鼠的身上进行试验 | 心理学家用老鼠来做试验 | 进行 + 试验 |
| 一架客机失事，造成九十八人死亡 | 一架客机失事，死了九十八人 | 造成 + 死亡 |
| apply pressure / give authorization / send a communication / take appropriate action | press / permit / write / act | 英文同类病，动作一分为二 |

## 四、伪术语：给平实的话套学术外壳

| 原句（病） | 改成 | 病灶 |
|---|---|---|
| 具有很高的知名度 | 很有名 | 「知名度」是造出来的名词 |
| 这本传记的可读性颇高 | 这本传记很好看（或：引人入胜） | 英文只用 readable，不用 readability |
| 昨晚的演奏颇具可听性 | 昨晚的演奏很好听 | 类推生造 |
| 岂不比一篇实验小说更具可看性 | 岂不比一篇实验小说更耐看 | 同上 |
| 更具前瞻性 | 更有远见 | 同上 |
| 富于爱国主义的精神 | 富于爱国精神 | 主义 + 精神，重复 |
| initial phase / communication | first step / letter | 英文伪术语 |

## 五、多余的复数：中文不靠语尾表多数

| 原句（病） | 改成 | 病灶 |
|---|---|---|
| 人们 | 人人、大家、大众 | 余光中称「人们」是丑陋的西化词 |
| 民众们、听众们、球员们 | 民众、听众、球员 | 「众」已含多数，再加「们」不通 |

## 六、「……之一」的泛滥

| 原句（病） | 改成 | 病灶 |
|---|---|---|
| 作为竹林七贤之一的刘伶以嗜酒闻名 | 刘伶是竹林七贤之一，以嗜酒闻名 | 「作为……之一的」把主语压在底下 |
| 红楼梦是中国文学的名著之一 | 红楼梦是中国文学名著 | 蛇足，没人会误会只有一部 |
| 李广乃汉朝名将之一 | 李广是汉朝名将 | 同上 |
| 他是最有名气的人物之一 | 他是赫赫有名的人物 | 「最……之一」自相抵消 |
| 我是听王家的兄弟其中之一说的 | 我是听王家的兄弟说的 | 港式「其中之一」 |

## 七、连接词：中文靠并列，不靠 and

| 原句（病） | 改成 | 病灶 |
|---|---|---|
| 柴、米、油、盐、酱、醋以及茶 | 柴米油盐酱醋茶 | 一长串同类词无须连接词 |
| 起步更早及迈步更快 | 起步更早、迈步更快 | 「及」破坏中文生态，要用也只能用「而」 |
| 慢及可靠 | 慢而可靠 | 同上 |

## 八、介词：「有关」「关于」「由于」多半是画蛇添足

| 原句（病） | 改成 | 病灶 |
|---|---|---|
| 欢迎王教授来到我们的中间，在有关环境污染的各种问题上，为我们作一次学术性的演讲 | 欢迎王教授来讲讲环境污染问题 | 「中间」「有关」「学术性的」全可删 |
| 今天我们讨论有关台湾交通的问题 | 今天我们讨论台湾交通问题 | 「有关」多余 |
| 关于他的申请，你看过了没有？ | 他的申请你看过了没有？ | 「关于」多余 |
| 关于一个河堤孩子的成长故事 | 一个河堤孩子的成长故事 | 十三字里两字无用 |
| 由于秦末天下大乱，所以群雄四起 | 秦末天下大乱，群雄四起 | 因果已在不言中 |
| 由于好奇心的驱使，我向窗内看了一眼 | 出于好奇，我向窗内看了一眼 | 啰嗦，且动用了大词 |
| 由于他的家境贫穷，使得他只好休学 | 他家境贫穷，只好休学 | 「由于……」不能当主语 |

## 九、副词「地」与「成功地」

| 原句（病） | 改成 | 病灶 |
|---|---|---|
| 他苦心孤诣地想出一套好办法来 | 他苦心孤诣，想出一套好办法来 | 「地」把成语降成副词，主客太分明 |
| 国父孙中山先生成功地推翻了满清 | 国父孙中山先生推翻了满清 | 推翻了就是成功了 |
| 成功地发明了相对论 | 发明了相对论 | 同上 |

## 十、「的」的滥用

| 原句（病） | 改成 | 病灶 |
|---|---|---|
| 一位衰老的、疯狂的、瞎眼的、被人蔑视的、垂死的君王 | 一位衰老、疯狂、瞎眼、被人蔑视、垂死的君王 | 五个形容词串五个「的」 |
| 参差的斑驳的黑影 | 参差而斑驳的黑影 | 单调重迭 |
| 弯弯的杨柳的稀疏的倩影 | 弯弯的杨柳投下稀疏的倩影 | 连用三个「的」，层次不明 |
| 灰暗的凄冷的天空 | 灰暗而凄冷的天空 | 两个「的」可省一个 |
| 夜色的来袭、风雨的将至 | 夜色来袭、风雨将至 | 名词化把有力的话泡软 |
| 白色的鸭 | 白鸭 | 单音节形容词不必带「的」 |
| 有不洁的颜色的都市的河沟 | 都市的脏河沟 | 乱用「的」，读者断错句 |
| 难度很高的技巧 | 很难的技巧 | 学术外壳的形容词 |
| 热情型的人 | 热情的人 | 同上 |
| 太专业性的字眼 | 太专门的字眼 | 同上 |

## 十一、长修饰语：前饰改后饰

前饰句以名词压底，一长就累赘；后饰句可以一路加下去，长而不失自然。余光中的说法：**前饰句是关闭句，后饰句是开放句。**

| 原句（病） | 改成 | 病灶 |
|---|---|---|
| 我见到一个长得像你兄弟的男人 | 我见到一个男人，长得像你兄弟 | 短句尚可，长句必崩 |
| 我见到一个长得像你兄弟说话也有点像他的陌生男人 | 我见到一个陌生男人，长得像你兄弟，说话也有点像他 | 形容词堆在名词前 |
| 项籍是一个身高八尺，力能扛鼎，同时才气过人的汉子 | 籍长八尺余，力能扛鼎，才气过人 | 原文（《史记》）本是后饰 |

## 十二、被动语气

中文以主动句为常；该用被动的场合，也不止「被」一个字（受难、遇害、挨打、遭殃、为世所重）。

| 原句（病） | 改成 | 病灶 |
|---|---|---|
| 我不会被你这句话吓倒 | 你这句话吓不倒我 | 生硬被动 |
| 他被怀疑偷东西 | 他有偷东西的嫌疑 | 同上 |
| 他这意见不被人们接受 | 他这意见大家都不接受 | 同上 |
| 他被升为营长 | 他升为营长 | 中文自明，无须被动 |
| 他不被准许入学 | 他未获准入学 | 同上 |
| 他被选为议长 | 他当选为议长 | 同上 |
| 他被指出许多错误 | 有人指出他许多错误 | 补出施者更自然 |
| 他常被询及该案的真相 | 常有人问起他该案的真相 | 同上 |

## 附录 A：搜索关键词

改稿时按这个顺序搜，命中率从高到低（也是 AI 中文最容易出问题的顺序）：

```
进行|作出|具有.{0,6}性|造成.{0,4}死亡|有关|关于|由于|成功地|之一|们|被
```

| 关键词 | 常见组合 |
|---|---|
| 进行 | 进行 + 研究／试验／讨论／优化／分析 |
| 作出 | 作出 + 贡献／反应／决定／判断 |
| 具有……性 | 具有很高的知名度、可读性、前瞻性、可扩展性 |
| 有关 / 关于 | 有关 X 的问题、关于 X 的讨论 |
| 由于 | 由于……，使得…… |
| 成功地 | 成功地 + 任何已完成的动作 |
| 之一 | ……之一、最……之一、其中之一 |
| 们 | 人们、开发者们、用户们 |
| 被 | 被认为、被广泛使用、被称为 |

## 附录 B：一句话原则

1. **主语用具体的东西。** 人、agent、这条消息、这段代码，不用「优化」「提升」「增长」这类名词当主语。
2. **动词直接说做了什么。** 能用一个动词就别用「动词 + 名词」。
3. **一句只说一件事。** 句子长了先拆，不靠「的」和逗号硬撑。
4. **能删的词就是多余的词。** 「有关」「关于」「进行」「成功地」删掉后，句子通常更好。
5. **别给平实的话套学术外壳。** 「很难」不必写成「难度很高」。
