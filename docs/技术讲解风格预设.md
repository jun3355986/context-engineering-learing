## 改版约定

1. 每次修改都新建 `技术讲解风格预设-vN.md`，**不改动旧文件**。
2. 新文件头写明版本号、日期、上一版链接、本版变更。
3. 回到本表加一行，并把「当前最新」改成新版本。
4. 旧版本不删——它们记录了某个判断当时是怎么来的，删掉就只剩结论。
