- `spec.md`：总规格（需求的唯一来源）
- `orchestrator-prompt.md`：主控 agent 提示词
- `issues/`：21 张任务票（按 to-tickets 规则拆分，一票一个文件）

## 三个阶段
- 阶段 1（01–09）：定方向。完成骨架、调研、大纲和 3 份样章，然后停下请作者确认。
- 阶段 2（10–14）：写主体。完成入门部分和主线 16 章，然后停下请作者确认。
- 阶段 3（15–21）：进阶与交付。完成进阶、源码解读、附录、集成和检查。
