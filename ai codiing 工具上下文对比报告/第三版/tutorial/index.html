先看地图，再决定怎么读

这套教程讲一件事：编码智能体（coding agent）的「上下文」是怎么被装进去、用掉、压缩和隔离的。所谓编码智能体，就是能读写代码、执行命令、自己迭代的那类 AI 编程工具；书里也简称 agent。读完入门部分，你能看懂 agent 在做什么；读完进阶部分，你能为不同场景设计策略，并说清代价。

  • 16 类上下文管理能力
  • 8 个编码智能体
  • L1–L5 五级能力
  • 54 章正文 + 5 篇附录

读完你能做到

  1. 说清一次请求里到底装了哪些东西，各自占多少。
  2. 判断一个 agent 在压缩、裁剪、隔离上做了什么取舍。
  3. 为自己的项目写一套上下文策略，并用评测数据证明它更好。

03 · 阅读方法

三种读法，按你手上的时间选

这套教程不要求从头读到尾。每一章都能单独打开，章内的小测验也是「先猜再看答案」，适合碎片时间。

只有 15 分钟：先建立框架

读导读 → 第 1 章「上下文窗口是什么」 → 第 7 章「总流程图」 → 第 15 章「压缩：把历史换成摘要」。目标不是记住细节，而是知道「上下文会满，满了要减量」。

系统学：按部分顺序

入门 7 章连着读，每章的「动动脑」先自己想一遍；再进主线，一章只解决一类能力。每章末尾的要点可以单独复制成笔记。

当手册查：带着问题跳读

用顶部搜索找章节，或直接翻附录的参数速查表和16 类总表。查到某个 agent 的做法后，记得看它旁边的可信度标签。

读法上的一个建议

遇到「动动脑」先停十秒，把答案写在纸上或心里过一遍，再往下看。直接读答案会很快，但记不住。

05 · 使用边界

关于 Claude Code 源码的声明

请先读这段

本教程的 Claude Code 部分，基于非官方渠道获得的 v2.1.88 源码快照分析，仅供学习参考，不代表 Anthropic 的官方实现，也不代表当前版本。源码与官方文档不一致时，教程会两边都写并标明差异；可能已经改变的行为标【可能已变化】。

这份源码可能经过打包或压缩后还原，函数名、变量名未必是原始命名。因此教程只做结构和行为层面的解读，不把变量名当作官方 API。每段原文摘录不超过 15–20 行，其余用伪代码、流程图和文字说明。

06 · 符号约定

看到这些标签，知道该信几分

教程里每个关于 agent 行为的说法都会带来源。标签不是装饰，它告诉你这条结论的证据强度。

已核实 推断 待核实
  • 已核实：在源码或官方文档里直接看到，并附了链接。
  • 推断：根据代码结构或运行行为推断，没有直接文字依据。
  • 待核实：还没核对，或两处来源冲突、暂未定论。
