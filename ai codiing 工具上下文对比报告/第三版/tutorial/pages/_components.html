组件示范页

这一页把教程里所有可复用的组件摆在真实页面里跑一遍。写章节时，从这里复制结构，再对照 CONVENTIONS.md 的说明填内容。

  • 8 个组件
  • 桌面 / 平板 / 手机
  • 深浅色都可用
  • 无外部依赖

这一页不是教程正文

页面里的工具名、参数、来源都是结构占位，不代表任何工具的真实行为。真正的结论由主线章节填入，并附来源与可信度标签。

C1 · 工具弹窗

点按钮打开，Esc 或点遮罩关闭

主线每一章都有 7 个工具按钮，点开后用弹窗讲该工具的做法、关键参数、设计意图和来源。弹窗内容较长时在内部滚动，不撑破页面。

用 #modal-pi 直接打开 也可以用地址栏哈希分享某个弹窗。

键盘：Esc 关闭；Tab 在弹窗内循环，不会跑到背后的页面。

C3 · 小测验

先猜，再点开答案

每章 3 道。答案默认收起，点击后才展开；展开后按钮变成「收起答案」，读者可以对照自己的猜测。

Q1

在 375px 宽的手机上读 8 工具对比表，怎么看到最右边的「来源」列？

解析

在表格区域左右滑动。表格容器可以横向滚动，第一列（工具名）用 position: sticky 冻结在左边，所以滑动时仍知道当前行是谁。

Q2

想直接把「pi 的工具弹窗」发给别人，链接应该怎么写？

解析

在页面地址后面加 #modal-pi。页面打开时会读取哈希并自动弹出对应弹窗；Esc、点遮罩或右上角关闭按钮都能关掉。

Q3

点了导航里带「待写」标记的章节，会发生什么？

解析

不会跳转。页面底部弹出一条提示，说明这一章还没上线；目录位置会保留，等正文补齐后自动变成普通链接。

C4 · 带中文注释的代码块

注释和代码，一眼分得开

源码解读里，注释用绿色斜体，整行注释再加一条左侧色条和淡背景。右上角「复制」拿到的是纯文本，注释会一起复制走。

TypeScript · 示意 
// 示例：上下文预算的粗略检查（伪代码，不代表任何工具的实现）
const LIMIT = 200_000; // 窗口上限，单位 token
const RESERVE = 16_000; // 留给模型输出的空间
 
function shouldCompact(used: number): boolean {
  // 先加上预留空间，再和上限比较
  return used + RESERVE > LIMIT;
}
 
// 压缩后仍要保留最近几轮原文，否则模型会忘记刚说的话
const KEEP_RECENT_TURNS = 3;

代码块自己的横向滚动条不会带动整页；行号由章节作者按需手写，组件不自动生成。

C5 · 可信度标签

三种可信度，三种来源类型

标签放在结论所在句子的后面，不要单独一行堆在段落开头。Claude Code 的结论至少带一个来源类型标签。

已核实 源码里直接看到这一行，并附了 permalink。

推断 代码结构显示如此，但没有直接文字说明。

待核实 两处来源冲突，或还没回源码确认。

源码 v2.1.88 结论来自 Claude Code v2.1.88 源码。

官方文档 结论来自 Anthropic 官方文档。

两者一致 源码与文档说法一致；不一致时两边都写，不合并。

组合用法

一句话可以带两个标签：已核实 两者一致。前者说证据强度，后者说来源类型。不要用「已核实」代替来源链接。

C6 · Head First 卡片

动动脑、没有傻问题、要点小结

入门部分每章至少各出现一次。三类卡片颜色不同，读者扫一眼就知道现在该思考、该看答疑，还是该收尾。

?动动脑

一章有 3 道小测验。你打算先读答案，还是先自己猜？先别往下翻，写下你的理由。

提示：回忆一下，上次「一看就懂、合上就忘」是什么时候。

Q没有傻问题

问：我不做 Agent 开发，读这套教程会不会太难？

答：入门部分只假设你用过至少一个 AI 编程工具，不要求读过源码。遇到不认识的术语，先查附录术语表，再回到正文；每章开头都会说明前置知识。

✓要点小结

  • 先猜再看答案，比直接读答案记得牢。
  • 术语第一次出现时，会给英文原词和例子。
  • 看到【推断】，说明结论还没有直接依据，别当成定论。
  • 每章末尾的要点可以单独复制，当作复习卡片。

C7 · SVG 图示容器

宽度自适应，图注在图下方

图示一律用内联 SVG，不引入图片文件。容器负责边框、内边距和背景，SVG 只写 viewBox，宽度交给 CSS，手机上和正文同宽。

C8 · 交互演示容器

统一的控制区 + 画布区

所有演示共用一个外框：上方是标题和「交互演示」标记，左侧（手机上在上方）放控件，右侧放画布。演示脚本放在 assets/js/demos/<名字>.js，本页只内联了一个最小示例。
