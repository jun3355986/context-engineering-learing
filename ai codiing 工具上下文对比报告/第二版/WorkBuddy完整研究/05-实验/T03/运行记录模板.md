# T03 · 运行记录模板

> 用法：把本文件复制成 `运行记录-<运行ID>.md` 再填。**一个运行 ID 一份**，不覆盖、不合并。
> 两类模板**必须分开填**（机制实验 / 产品组合观察），字段不同、结论强度不同。
> 判据一律来自检查器（见 `实验规程.md` §5）。

## 0. 运行标识（两类都要填）

| 字段 | 值 |
|---|---|
| 运行 ID | `MECH-...` 或 `PROD-...` |
| 运行日期 / 时区 | |
| 执行者 | |
| 对应场景 | E1 关键约束保留 / E2 大工具输出 / E3 连续三次压缩 / E4 重启恢复 / E5 单轮长工具循环 / E6 错误恢复 |
| 任务数据包 ID + 版本哈希 | `T03-DATA-TRIP-v1` 或 `T03-DATA-COMPAT-v1` + 整包摘要哈希 |
| 实际执行的可执行版本 | 运行入口自报（如 `codex --version` / `claude --version`） |
| 研究快照 SHA / 冻结分发包 | 取自 `00-管理/版本表.md` |
| 两者是否一致 | 一致 / 不一致（不一致时写落后方向，并计入归因限制） |
| 模型 / provider / 登录方式 | |
| 生效配置与覆盖 | 窗口、触发配置、门控开关的实际值 |
| 原始日志路径 | |
| 状态 | `OBSERVED / NOT_RUN / UNOBSERVABLE / FAILED` |

> **行号口径（E2 大工具输出场景必看）**：记录"关键事实在头/中/尾哪里"时，必须写**文件行号**（第 N 行，1 起），
> 不要写"班次序号/用例序号"之类的内容内编号——两者数值可能接近但不相等（实例：行程包推荐班次在**文件第 152 行**，
> 其班次序号是 **L7-141**）。引用长结果位置统一用双标 `文件行号 / 内容序号`。
> 校验入口：`python3 <工作区>/scripts/locate_keyfacts.py <数据根>`（缺失会报 `[缺失]` 并非 0 退出）。
