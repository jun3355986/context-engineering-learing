# 样本说明 · 长工具结果-公交查询-v2

## 0. 这个文件解决什么

**pi 出口截断测试需要一个超过 pi 限值（2000 行 / 50KB）的长工具输出**（Q14①：v1 样本仅 300 行 / 22,003 字节，低于阈值，触发不了截断）。本样本（v2）是**同宇宙、同结论**的「审计全量版」，用于：
- 观察 pi（及其他工具）在**超过出口限值**时如何截断（保头？保头尾？留标记？）；
- 截断后**关键事实（头/中/尾）哪一段存活**、中间段能否从磁盘原文找回（对齐 T03 规程 E2「大工具输出」条目）。

观察点（对齐 T03 规程 E2 + 各工具研究包）：
1. 工具**出口是否截断**（行数/字节阈值）、截断形态（头/头尾/标记）；
2. 截断后**中段（1339–1344）是否存活**；若丢失，磁盘原文（本文件本身）能否找回；
3. 工具是否给出「已截断」的**可见提示**（vs 静默截断）；
4. 记录必须引用本 README 的行号表，避免"行号漂移"误读。
