## 4. 多宽度检查记录

**方法**：Playwright 驱动系统 Chrome（headless），对 **320 / 390 / 768 / 1440** 四个宽度 × **9 个单元**（导览 + 7 台 + 附录）= **36 项**，逐项检测 `document.documentElement.scrollWidth`（页面级）与 `.interact / .tblwrap / pre / .colcard / .mlist / .seg / .logbox / .calc-grid / .threecol / table`（元素级 `scrollWidth − clientWidth`）。

**结果：36/36 全部无横向溢出**（判定阈值 > 1px）。

| 宽度 | 布局表现 |
|---|---|
| **1440** | 侧栏常驻（≥1000px grid 布局）；卡片式排布；表格常规渲染 |
| **768** | 侧栏抽屉（<1000px），顶栏「目录」按钮唤出；`.calc-grid` 2 列；`.threecol` 单列 |
| **390** | 单列；`.calc-grid` 1 列；表格转「卡片式」（`td::before` 显示字段名） |
| **320** | 最小宽度仍可读；表格卡片式；无竖排挤压；字号降级（`body 15.5px`、`pre 12.8px`） |

**修复记录（本轮发现并修复）**

## 5. 离线可用性与官方入口

- **官方内容处理**（满足「原版入口 + 嵌入回退 + 中文复现明确标注」）：
