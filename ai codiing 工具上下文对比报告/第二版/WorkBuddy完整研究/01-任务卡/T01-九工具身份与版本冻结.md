**完成条件**（逐项可判断）：
- 九行身份表每行都有可点击的官方来源 URL；名称能唯一定位（不猜仓库）。
- 开源工具：`workbuddy-sources/<tool>/` 存在完整克隆，SHA 为 40 位完整值，与 `git rev-parse HEAD` 一致；下载日志含日期。
- 闭源工具（如 Claude Code）：官方分发包版本 + npm tarball sha256 + 获取日期；**不得**使用社区还原目录冒充官方实现（可登记为"社区线索"单独标注）。
- 四组歧义（OpenCode v1/v2 版本定义；pi/oh-my-pi 来源关系；Grok Builder 产品身份；deepseek-harness 定位）各有明确调研结论或明确的"未能确认"。
- 新快照与旧 `sources/codex` 分开登记，互不覆盖。

**复核**：独立审查 Agent（T01R）将抽查 ≥3 个仓库的 SHA 与官方 URL 可达性、Stars 记录日期；主 Agent 验收后合并进 `00-管理/版本表.md`。

**边界**：
- 只研究 CLI/工具本身；Desktop/云端产品不在范围（Codex 已明确只研究 CLI）。
- 无法定位的对象写"待确认"，**不得自行替换**为用户没提过的对象。
- 遇到需要付费/登录才能取得的闭源材料：只登记官方公开来源，不购买、不绕过。
- 大仓库克隆控制体积：可 `--depth` 浅克隆**但必须能取到完整 SHA**；若浅克隆不可行则完整克隆；记录所用方式。
