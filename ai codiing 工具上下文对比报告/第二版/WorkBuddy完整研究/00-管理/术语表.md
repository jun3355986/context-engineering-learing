# 术语表（公共登记）

> **全研究唯一术语来源**：课程母稿、九工具研究包、平台稿引用同一语义，不得各自起名。
> **排列纪律（HF §0）**：每条"中文名 + 英文原词 + **最小例子（先看这个）** + 一句话定义"；术语不裸奔、例子先行。
> **来源标记（4 类）**：`新增`（本次系统化新增）｜`补基线`（样章基线已确立，此处补例子/层级）｜`待工具任务确认`（=**待核验**；语义或产品行为须 T04–T13 核验，**在此之前不得在课程母稿当既成事实**）｜`已证`（有固定证据已证实 CLI 侧；服务端部分待 T19）。
> **待核验清单（6 条）**：系统提示词、后续标志、模型切换触发、摘要漂移、后台提取、缓存存活期。另有"缓存键"=已证（CLI 侧；**dsh 侧不成立**——未发现 CLI 缓存键，T13R）。
> **层级标记**：`L1`～`L5` = 建议首次出现层级（对应 `03-课程/T02/五级覆盖图.md`）。
> **边界强制（"≠"）**：缓存 ≠ 摘要 ≠ 外部记忆 ≠ 容量扩展（见 §3/§5/§6 与 `03-课程/T02/数据地图与机制辨析.md` §2）。
> **命名收口**：`replacement_history` 统一"**替代历史**"（别名"替换历史"，见勘误 **E-01b**）；触发判定固化为**三层结构**（伞名/拆名/判定用语，见 §2 注②）。勘误全表见 `00-管理/冲突表.md` §4（E-01 已于该处拆分为 E-01a/E-01b，引用可写"E-01（a/b）"）。
> **数字与术语分离**：表中"最小例子"里的数字只是**举例**；真实常量须按 §12 三类角标（【源码常量】/【演示】/【测试样本】）标注，不得把例子当阈值。

| 自动整理限额 | auto compact token limit | 模型元数据字段 M = 150,000 | **= 模型元数据字段 M**（示例 150,000）；范围线 = min(M, 90%W)（无 M 用基础线；窗口未知用字段，见下注①） | L3 | 新增 ｜ 见注① |
| 触发线（伞名） | compaction threshold（umbrella） | 到线时触发整理 | 触发判定的总称：**触发线 = 范围线 OR 整段线**（见下注②；课程与 CM-05 主用） | L3 | 补基线（伞名保留） |
| 触发到线 | trigger reached | A ≥ 范围线 **或** A ≥ 整段线 | 判定用语："到线了"的状态表述（见下注②） | L3 | 补基线 |

| 分词器 | tokenizer | 同一句话在两家模型切法不同 | 把文本切成 token 的服务端规则 | L3 | 新增 |
| 饱和减法 | saturating_sub | A−P 为负时结果夹到 0 | 防下溢的整型安全减法 | L4 | 新增 |

> **注①（自动整理限额定义，主 Agent 裁决 F4）**：**以源码证据为准**——「自动整理限额」**= 模型元数据字段 M**（`auto compact token limit`）；「**范围线**」**= min(M, 90% 基础线)**（无 M 时用基础线；窗口未知时直接用字段）。样章母稿**附录 A（行 1686）**的"= min(...)"表记按**勘误 E-01a** 处理（不改基线，复用时修正）。依据：结论表 `codex-trigger-02`；待 T04 固定快照复核。　另：该 M 字段口径为 **Codex 专有**；dsh 无 M 字段（触发=双上限公式），**不得套用**（T13R）。
>
> **注②（触发线族三层结构，主 Agent 裁决 F3）**：固化为**三层**——**伞名「触发线」**（判定总称；课程与 CM-05 主用）｜**拆名「范围线」「整段线」**（母稿 U03 行 424/437 用）｜**判定用语「触发到线」**（"到线了"的状态表述）。关系：**触发线（伞名）= 范围线 OR 整段线；"触发到线"= 该 OR 判定为真**。不得当成两套机制。
