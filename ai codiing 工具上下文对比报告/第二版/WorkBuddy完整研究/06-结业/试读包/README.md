# 试读包 · 怎么用

> **这是什么**：一套**最小试读材料**，让**真实读者**在不依赖 Agent 自评的前提下，走一遍"前测 → 任务 → 迁移 → 反馈"的闭环，用来验证课程（T15 母稿 + T18 结业包）的**教学效果**。
>
> **教学效果状态：`待验证`。** 本包只提供**流程与量表**，**不包含任何 Agent 自评分**——在真实读者完成并回收反馈表之前，"教学效果"一律标注为**待验证**，**不得**用 Agent 模拟作答或自评冒充读者验证结果。

---

## 一、给谁用

| 角色 | 怎么用 |
|---|---|
| **试读者**（真实的人，零基础或开发者均可） | 按 §二 顺序：先做**前测**，再读课程，再做**任务**与**迁移**，最后填**反馈表** |
| **组织者 / 研究者** | 负责分发、计时、回收反馈表；把回收结果登记进本目录（见 §四），**不得代填** |

---

## 二、试读顺序（四步）

1. **前测**（`前测.md`，5 题，约 10 分钟）——**先做**，测的是"读之前你已知道什么"，**允许不会**，不会也如实记录。
2. **读课程**（**不在本包内**，按试读者水平选）：
   - 零基础：从 `../../阅读入口.md` → `03-课程/T15/T15-导览.md` → **M01 → M02 → M03**（起步三单元，约 1.5~2 小时）；有余力再选一个后期单元（如 M05 工具输出治理）。
   - 开发者：可跳过 L1/L2，从 **M03（预算与触发）** 或 **M10（源码桥接导引）** 进入。
3. **任务**（`任务.md`，题组 A 简版，约 40 分钟）——检验"讲过的场景"能否独立完成（组装请求 / 预测损失 / 保留策略）。
4. **迁移**（`迁移.md`，题组 C 简版，约 40 分钟）——检验能否把机制**迁移到新场景**（带否决决定的多子代理并行长任务）。
5. **反馈表**（`反馈表.md`）——逐题记**错误 / 提示依赖 / 用时**；**卡点**写进"卡点清单"。

> **纸面可完成**：任务与迁移**都不需要运行任何工具或模型**；所需数据在题面内联（简版已把关键数据摘出）。唯一"动手算"的是预算演算（参数标【演示】）。

---

## 三、边界（如实声明）

- **本包不产生"教学效果结论"**：只有**回收到的真实读者反馈**才能支撑结论；在回收前状态恒为 **`待验证`**。
- **不排名次**：任务与迁移**不比较工具优劣**；预算演算是**教学假设**（标【演示】），**不是任何工具的实测阈值**。
- **未知保留未知**：凡课程标 `【T19 待回填】` / `保留未决` / `不可观测` 处，试读者**不得**被要求给出"确定答案"；反馈表对这类题按"是否**识别出未决**"计，而非按"猜对数值"计。
- **简版口径**：本包 `任务.md` / `迁移.md` 是 `../../06-结业/T18-任务包.md` 的**简化版**（保留核心小问、压缩数据摘录）；**完整版与参考解答**见 `T18-任务包.md`、`T18-参考解答与评分.md`（**组织者批改用，试读者做题时不得查看**）。
