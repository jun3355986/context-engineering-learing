## 二、导出方式（可复现）

- **脚本**：`/tmp/t20-svg-shot.js`（playwright-core + 系统 Chrome，与 `03-课程/T17/build/shot.js` 同模式）。
- **运行**：
  ```bash
  export NODE_PATH=<NODE_PATH>   # 本机 node 依赖目录（含 playwright-core；按环境替换）
  export SVG_DIR="<本目录>" PNG_DIR="<本目录>" SCALE=2
  <NODE> /tmp/t20-svg-shot.js   # <NODE>=node 可执行文件（按环境替换）
  ```
- **参数**：Chrome 路径 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`；`deviceScaleFactor = 2`（2× 清晰度）；对每张 SVG 的 `<svg>` 元素整幅截图。
- **输出**：`S1.png … S21.png`，像素宽 **2400**（= 1200 × 2），高按内容（1240–1800）。
- **底色**：画布为浅色主题底 `#f4f6fb`（非透明），与 T17 交互教材 CSS 变量一致。

### 样式基准
配色取自 `03-课程/T17/交互教材.html` 的 CSS 变量（浅色主题）：`--bg:#f4f6fb`、`--ink:#1b2330`、`--brand:#2952cc`、`--teal:#0d9488`、`--ok:#15803d`、`--warn:#c2410c`、`--bad:#b91c1c`、`--line:#dfe5ef` 等。中文字体 `system-ui / PingFang SC`。每张图左上角有「上下文管理 · S编号」小字标识。纯 SVG、内联 `<style>`、无外部依赖。
