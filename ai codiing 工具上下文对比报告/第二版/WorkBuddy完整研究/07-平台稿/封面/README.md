## 三、生成方式（可复现）

```
build/gen.js   # 读标题数组 -> 合成 35 个 SVG（基图 <image> + 大字标题 + 角标 + 底部小字）
build/shot.js  # playwright-core + 系统 Chrome，逐个 SVG -> PNG
```

运行：

```bash
cd 07-平台稿/封面/build
<NODE> gen.js   # 按环境替换
NODE_PATH=<NODE_PATH> \   # 含 playwright-core（按环境替换）
<NODE> shot.js
```

要点：
- 基图以 `<image xlink:href="bases/Bx-*.png" preserveAspectRatio="xMidYMid slice">` 铺满画布；
  公众号（3:2）与小红书（3:4）基图与画布**比例完全一致、无裁切**；
  博客 OG 为**标准 1200×630（1.91:1）**，基图 B5（3:2）按 slice 居中裁去上下各约 85px（标题区上下留白，裁剪安全）。
- 标题**中文字重 800**，字号按「内框宽度 ÷ 每行字宽」自适应；**最多两行**，
  断行优先落在标点后（`：，。？！—` 等），破折号 `——` 不拆开。
- 文字区加 **90% 白半透明圆角衬底**（保证深色基图上的可读性）+ 左侧蓝色强调条。
- 角标：左上「上下文管理 · 八工具实测」、右上「第NN篇 / 第NN条」。
- 底部一行小字（10% 高白色页脚带）：「八工具实测 · 有来源可查」。

## 五、复用说明

- **改标题**：编辑 `build/gen.js` 里的 `gongzhong[] / xhs[]` 数组 → 重跑两条命令即可。
- **换基图**：替换 `bases/B*.png`（保持同名同比例 3:2 或 3:4）→ 重跑即可；也可在 `gen.js` 里改轮转规则。
- **换配色**：`gen.js` 顶部 `ACCENT / TEAL / INK / SUB` 四个常量统一控制。
- **导出别处尺寸**：改 `gen.js` 里 `GW/GH`（公众号）、`BW/BH`（博客 OG）或 `XW/XH`（小红书）。
- SVG 用**相对路径**引用基图，**必须连同 `bases/` 一起移动**才能正常渲染；
  若需单文件自包含，可把基图转 base64 内联（当前未内联，避免 SVG 体积过大）。
