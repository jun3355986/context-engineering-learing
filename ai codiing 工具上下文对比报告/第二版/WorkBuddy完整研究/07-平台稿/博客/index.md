# AI 上下文管理 · 完整教程入口

> **这是什么**：一份"Agent 上下文管理"主题的**完整学习与查证入口**。它回答一个日常问题——**为什么 AI 明明"记得"，这一次却没把该用的材料用上**；并顺着这个问题，把"一次回答到底看了哪些材料、什么时候整理、压缩丢了什么、关掉再打开还剩多少"一层层讲清楚。
>
> **给谁看**：想弄明白 AI 上下文机制的**普通读者**；要落地配置的**开发者**；要核对每个数字出处的**查证者**。**不要求**读完八份工具研究报告。
>
> **五级路线（一句话）**：**L1 建立直觉 → L2 理解流程 → L3 掌握机制 → L4 连接源码 → L5 独立判断**；每一级都要求读者"**做出一个东西**"，不是只读目录。
>
> **可停靠级（可停在哪，不虚报）**：停在 **L1/L2** = 读懂文章不发懵；停在 **L3** = 能算账、能选策略；完成 **L4+L5** = 对应"上下文管理专项中级"（**仍需练习与迁移验证**，见文末状态说明）。

## 怎么读（三条纪律，先看一眼）

1. **材料分三层，别混**：**保存的记录（磁盘）** / **当前材料（内存）** / **实际请求（真正影响模型的那一份）**。你"看到了"不等于"模型看到了"。
2. **数字带角标**：【源码常量】（固定快照里的真实常量/公式）｜【演示】（教学假设数字，**不得**当阈值）｜【测试样本】（仓库自带测试数值，**未运行**）；实测值写"【T19 实测：…】"并给**版本条件**。
3. **未测就写未测**：`未测（原因）` 或 `不可观测（原因）`；**`NOT_RUN` ≠ 机制不存在**。
