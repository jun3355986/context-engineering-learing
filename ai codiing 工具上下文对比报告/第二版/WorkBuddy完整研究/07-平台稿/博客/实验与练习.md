## 一、练习（结业任务）

### 1.1 三题组

| 题组 | 场景 | 子题 | 落点 |
|---|---|---|---|
| **A · 行程任务** | 讲过的场景（郊游：读目标 → 多轮讨论含 3 次否决 → 长工具结果 → 会话整理 → 隔天恢复 → 出最终方案） | A1 独立组装一次请求；A2 预测哪些约束会丢；A3 给出保留策略 | 组装 / 信息损失 / 保留策略 |
| **B · 接口兼容** | 接口字段增删与兼容判定 | B1–B3（含 **B3 源码桥接**：在固定行号里指出分支） | 结构不变量 / 源码 |
| **C · 迁移任务** | **未做过完整设计的新场景** | 独立设计 + 排障 | 设计 / 评估 / 迁移 |

- **纸面可完成**：题组 A/B 的**任务数据**（消息序列 / 约束 / 长结果 / 坏摘要）**内联在题面**，无需打开数据文件；**全程不需要运行检查器、不需要真实模型**。
- **唯一需动手算的**是**预算演算**（题组 A3 第 4 小问）：参数由题面给定并标注 **【演示】**，是**教学假设**，**不是任何工具的实测阈值**。
- **编码选做**（另交）：三题（E1/E2/E3）最小实现与运行检查，需运行 `python3`（纯标准库，不联网、不调模型）——**选做**。

### 1.2 评分口径（六项能力，**分别**评三级）

> **铁律**：六项能力（①解释信息流 ②推演预算与信息损失 ③选择策略 ④阅读核心源码 ⑤设计与排障 ⑥评估与迁移）**逐项**评「**已展示 / 需提示 / 尚未展示**」，**不得用"总分"或"平均分"掩盖某一项的缺口**。

| 能力 | 已展示（证据充分） | 需提示（部分具备） | 尚未展示（缺口明显） |
|---|---|---|---|
| ① 解释信息流 | 说清"保存的记录 / 当前材料 / 实际请求"**三层差异**，且举出**自己的一个反例** | 能说三层差异，但举不出自己的反例 | 把三层当一层；说不出"我看到了 ≠ 模型看到了" |
| ② 推演预算与信息损失 | 算例**含单位与条件**，且能指出**一处"会丢约束"的具体环节** | 会算线但条件/单位不全，或定位不到具体那一处 | 不会算线；或把"约束丢了"一律归因于"压缩" |
| ③ 选择策略 | 场景 **> 1 个**，每个选择给出**代价**与**一个反例** | 有选择但缺代价或反例 | 只会"选一个"，或写成"排名" |
| ④ 阅读核心源码 | 在**固定链接（含 SHA）**里指出触发/保留/**写回**三个分支的状态变化 | 能指出一两个分支，或缺 SHA / 缺前后状态 | 指不出分支；或把闭源工具写成"源码" |
| ⑤ 设计与排障 | **四份交付物完整**（状态图 / 伪代码 / 失败处理 / 检查方法），失败表含"**不可重复的副作用**" | 四份缺一件，或失败表漏副作用/幂等 | 只交状态图与伪代码；无检查方法 |
| ⑥ 评估与迁移 | **迁移任务完成**（对照表），验证方案**区分实测 / 推断** | 迁移部分完成，或未区分实测/推断 | 未迁移；或把推演当实测 |

**两条读表提醒**：① L5 主落点是 ③⑤⑥；①②④ 在 L5 是**附带复现**，但**六项都要分别评**——某项打「尚未展示」就回对应单元补；② 「**需提示**」是正常的——两三项需提示**不代表没学会**，代表**还需练习与迁移验证**。

### 1.3 补学入口（逐题 → 单元 / 源码节 / 附录）

### 2.3 六场景覆盖（§2.2 摘）

| 场景 | 覆盖情况（要点） |
|---|---|
| **E1 关键约束保留** | 八工具**单次压缩后核心约束全部 PASS**（判据=检查器；人工复核否决复活 0） |
| **E2 大输出头中尾** | codex 保头尾+标记 / pi 50KB 字节阈值（bash 保尾、read 保头）/ claude 落盘+预览 / omp middle / dsh 51200B 先到 / ocv1 bash 纯 tail / grok 头尾各 10,000 字符 / ocv2 shell 纯 tail |
| **E3 连续三次压缩** | claude 前 2 成第 3 拒 / pi 摘要单调增长 / dsh 9 份摘要 / **grok 3 次后硬约束丢失（首例直证）** |
| **E4 重启恢复** | codex 6/6 重述 / pi 路线 B 三证 / claude 3/3 不主动重述 / ocv1 6/6 / grok `-r` 生效 / ocv2 续同一会话 |
| **E5 单轮长工具循环** | pi 自主分页 / omp artifact 精确取回 / codex 二次检索取回 |
| **E6 可控错误** | pi 溢出注入=1 次恢复 / ocv1 doom_loop 拒绝 / grok 网络超时重试 |

### 2.4 未测项与不可观测（§4 摘）

- **未测（NOT_RUN + 原因）**：各工具手动 `/compact`（headless 无适配器）／部分 fork、子代理、记忆条件（依赖 TUI）／ocv2 native 通道（隔离环境 0 模型声明）等。
- **不可观测（UNOBSERVABLE + 原因）**：**服务端缓存命中率 / TTL**（结构不可观测，各工具均如实标）／压缩产物 `encrypted_content` 不可解密→摘要保真度不可判／真实分词（各工具 tokenizer）／费用（订阅或代理不可核验）等。
- **原则**：`NOT_RUN ≠ 机制不存在`；**"未发现" ≠ "没有"**。

### 2.5 结论修正表（§5 摘，14 条）

实测对早期结论的处置分五类：**升格**（如 codex 保头尾+标记，干净环境复现成立）／**修正**（如 omp 产品侧 bash=middle）／**限定**（如 claude 触发百分比方向未复现、机制不可观测）／**否证**（如 Grok 早期 `65536` 字节常量未成约束）／**更正**（如 OpenCode v2 shell 路径为**尾向**，"head-only"在 shell 路径被推翻）。**详细逐条见结果总表 §5。**

### 2.6 检查器已知局限（§6，**不修改冻结检查器**）

| # | 现象 | 处置 |
|---|---|---|
| 1 | 否定动词表未含"未采用"→ 误报 | 人工复核纠正；建议后续版本补词表 |
| 2 | 标题式否定语境不被启发式识别 → 误报 | 同上；改写为内联否定后复跑 PASS |
| 3 | 对全 null 字段求和=0 → 空真 PASS | 登记；建议后续版本区分"无数据"与"求和为 0" |

### 2.7 操作陷阱附录（§7，供复跑者）

1. **沙箱 rmdir**（部分工具）：workspace 下 `rmdir` 被拒 → 锁不释放；处置=挪 `/tmp` 或覆盖目录变量。
2. **tmux 驱动 TUI**：启动确认默认 No 会退出（需 Down+Enter）；流式输入需加节奏。
3. **对活跃 TUI 会话**报 `active writer` 冲突：关会话后重试。
4. **stub 注入**必须在**同一 shell 调用内**启停。
5. **窗口/阈值覆盖优先**：各工具用设计内调参入口控制填窗成本——**先小任务验证入口**。
6. **E1 提示词口径**：向模型要结构化判据时**显式给出键名**（否则见"自造键名→缺键 FAIL"）。
7. **低阈值停轮线**：阈值压得过低会"每步触发压缩"——先算好下限再跑。

## 三、回填清单（15 主题，公开摘录指引）

> **用途**：把课程中 `【T19 待回填】` 标记（原 106 处）归并为 **15 个主题**，逐主题给**回填值**（全部引用实测记录，不编造）。

| # | 主题 | 回填要点（公开摘录） |
|---|---|---|
| 1 | **连续压缩失真** | 单次/多轮压缩后约束**基本未丢**（判据全 PASS）；**grok 为首例反例**——3 次连续压缩后**硬约束丢失**（模型如实承认"不能确定"，**非复活非幻觉**）；**失真程度未量化** |
| 2 | **服务端缓存命中率 / TTL** | **CLI 侧** cacheRead 可观测且 >0；**服务端命中率/TTL 仍不可观测**；**不得承诺命中率** |
| 3 | **恢复后幂等 / 重复执行** | E4 条件下**未见工具重复执行**；**专门副作用注入未做** → **保留未决**（"未见重复 ≠ 保证不重复"） |
| 4 | **能力 ≠ 行为（按需读入）** | pi 同条件 3 轮**行为分化**；codex 中段丢失后**二次检索取回**；omp **精确取回** → 工具存在只证**能力** |
| 5 | **工具输出端到端默认行为** | 八工具截断形态（见 §2.3 E2）；**落盘完整性边界**：ocv1 一条路径观察到**缺头竞态**（恒后缀，**根因未证**）——引用"落盘可找回"须带此边界 |
| 6 | **claude 默认触发百分比** | 实测触发于 **≈98%**；override 语义**不可观测**；**默认百分比仍未公布** |
| 7 | **真实 tokenizer 与计费** | dsh 启发式对中文**低估 ≈2.1×**；部分工具 cost=0 可核验；多数订阅/代理**费用不可核验**；**真实分词仍不可观测** |
| 8 | **失败注入** | pi 溢出注入=**恰好 1 次**恢复；ocv1 doom_loop 拒绝；**其余工具失败注入未做** |
| 9 | **性能与成本对比** | 用量数据已录，但**执行模型/provider 不同 → 条件不可比，仍不排名次** |
| 10 | **远端产物明文 / 成功率** | 压缩产物为**加密条目**（不可解密）→ 摘要保真度**不可判** |
| 11 | **记忆 / 子代理深层语义** | **未覆盖专项** → **保留未决**（部分工具 memory 不可观测） |
| 12 | **评估四维现状** | 四维**均可填"已运行"**：质量=检查器全 PASS；成本=用量已录；延迟=耗时已录；可恢复=恢复后重述检查 |
| 13 | **grok 相关** | `/rewind` **不还原磁盘文件**（裁决）；截断=**头/尾各 10,000 字符**；触发线=**下限判定线**（读数 ≥ 阈值）；硬清→**成本 ×2.9** |
| 14 | **ocv2 相关** | 截断更正（shell=**纯 tail**）；keep=固定 15000；prune/tail_turns=不支持；native 通道**环境不可达** |
| 15 | **纪律声明类** | **不改**（描述标注体系本身的句子） |
