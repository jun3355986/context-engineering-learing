# AI 上下文管理 · 交互双入口

> **为什么是"双入口"**：交互内容**不能假设**读者能运行脚本。所以每个复杂交互都同时给两份——**① 交互 HTML**（动手拨参数看机制）与 **② 静态替代**（**同数据**的文字/表格版，无 JS / 打印 / 阅读视图可用）。
> **实物位置**：两件**复制件**放在本博客的 `assets/` 目录（**原样复制**，未改动交付件本身）：
> - `assets/交互教材.html`——**单文件**交互教材（内联全部 CSS/JS，**无外部依赖**，`file://` 可离线打开）
> - `assets/T17-静态替代.md`——每个复杂交互的**同数据**静态版
> **一致性纪律**：静态替代的数字、条件、状态与交互 HTML 的默认样例**逐项同源**，并**逐项回课程母稿核对**。

---

## 一、交互 HTML（`assets/交互教材.html`）

**形态**：**单文件**、内联全部 CSS/JS、**无 CDN / 无外部字体 / 无图片外链**；`file://` 可离线打开。

**规模**：**7 台实验台、8 个交互容器、7 组预测题、21 个"先猜后看"**。

| # | 实验台 | 形态 | 关键控件 | 对应单元 |
|---|---|---|---|---|
| ① | 预算/触发演算器 | 四本账 + 八工具口径切换，**5 步逐步演算** | 6 输入 + scope 选择 + 工具选择 + 4 预设 + 上一步/下一步/连续播放/暂停/重置/查看完整结论 | M03 |
| ② | 裁剪器 | 300 行条带 + **5 步逐步裁剪** | 预算滑块 + 位置选择 + 逐步/播放/暂停/重置 | M05 |
| ③ | 压缩四幕 | **8 幕演推** + 两样例切换 | 上一步/下一步/连续播放/暂停/重置 + 速度选择 + 步点回看 + 样例切换 | M04 |
| ④ | 状态机 | **四态 × 三层**（压缩前/压缩后/关闭/重开） | 四态按钮 + 逐步/播放/暂停/重置 | M06 |
| ⑤ | 检索/记忆/交接 | 按需读入 **3 步** + 全量装填对照 + **三问判断卡**（8 工具切换） | 逐步/播放/暂停/重置 + 模式切换 + 工具切换 | M09 / M08 |
| ⑥ | 账单器 | **4 账逐账** + 拆账输入 + 场景决策表 | 3 输入 + 4 账切换 + 上一账/下一账/连续播放/暂停/重置 | M07 / M11 |
| ⑦ | 时间线/演化器 | **7 步请求组装生长** | 上一步/下一步/连续播放/暂停/重置 + 速度 + 步点回看 | M02 |

> **⑤ 含两个交互容器**（"交互 A 检索" + "交互 B 三问卡"），故 **7 台实验台 = 8 个 `.interact` 容器**。

**每台六项必备要素**：默认样例 / 参数说明（角标标"源码常量 / 演示"）/ 逐步·暂停·回看·重置 / 预测题（先猜后看）/ 数据表 / 答案反馈（另有 3 道自测，共 21 个"先猜后看"）。

**离线可用性**：单文件、全部内联；唯一外部引用是**正文里**的官方缓存文档链接（**非渲染依赖**）——**离线打开时全部讲解与交互正常工作**。

## 二、静态替代（`assets/T17-静态替代.md`）

**形态**：交互 HTML 里每个复杂交互（①–⑦）的**同数据静态版本**，供**无 JavaScript**、打印、阅读视图或纯文本审阅场景使用。

**覆盖**：① 预算/触发演算器（默认样例·静态）→ ② 裁剪器 → ③ 压缩四幕 → ④ 状态机 → ⑤ 检索/记忆/交接 → ⑥ 账单器 → ⑦ 时间线/演化器。

**引用纪律**：数字带三类角标（源码常量 / 演示 / 待回填）；**不排名次**；`【T19 待回填】` 一律按「演示」对待；未知保留未知。

> **静态替代是默认样例的冻结快照**：改参数看结果需用交互版（浏览器启用 JS）。

---

## 三、发布说明（不假设读者能跑脚本）

- 交互内容**另配静态图/文字**；**不假设**公众号/小红书读者能运行脚本。
- 博客**同时给两个入口**：能运行脚本的读者用 HTML；不能的用静态替代 + 现成截图。
- 交互中的数字**不编造**：所有"演示"数字为机制推演或文档示例，**不作为结论**。

## 五、未决与边界（如实列出）

1. **教学效果未验证**：未做真实读者试读。
2. **无真实模型实验**：教材未编造任何保留率/费用/时延实测数据；"演示"数字为机制推演或文档示例。
3. **官方页面未来变化**：教材内官方外链为正文引用；**当前会 302 重定向到 `developers.openai.com`（HTTP 200）**——落地域名可能再变，失效不影响离线内容。
4. **浏览器覆盖**：仅在 Chrome（headless）验证；未在 Safari / Firefox / 移动端真机逐项复验（布局为纯 CSS 断点，风险低但未实测）。
5. **未排名次**：全文不含排序性表述；数字相同处显式标注"**数字相同 ≠ 机制相同**"。
