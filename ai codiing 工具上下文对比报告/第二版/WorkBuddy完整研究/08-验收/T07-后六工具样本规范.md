## 2. 证据卡格式（任务书 §4.4，逐字段强制）

```yaml
结论ID: <tool>-<mechanism>-<number>          # 前缀：omp/ocv1/ocv2/gemini/grok/dsh
结论: 一条有范围的判断（不写无限定的绝对句）
性质: 事实 / 推断 / 建议                      # "没有实现"类断言必须是"推断"或"不适用"
范围: 产品入口、版本或完整SHA、模型、provider、配置
实现状态: 默认 / 条件 / 实验 / 桩或空实现 / 未证实
来源: 官方URL或固定SHA链接、文件、函数、行号（链接基址写清）
数据走查: DW-*（无则写 —）
运行证据: 实验ID，或 NOT_RUN + 原因
不能证明: 当前证据不能外推到什么（必填，禁止留空）
冲突裁决: 支持/限制/撤回哪个旧结论，为什么
核验日期: 实际日期
```

**硬规则**：
1. **每个高风险主张必带"不能证明"栏**；空栏视为不合格。
2. **固定 SHA 链接**：开源用 `blob/<full-sha>/path#L起-L止`；闭源用官方文档 URL + 分发件版本/哈希。
3. **性质与实现状态分开**：`性质`说的是判断类型，`实现状态`说的是代码/产品里的落地程度；**接口名/桩函数 ≠ 默认行为**。

|---|---|---|
| CM-01 | 请求组装与角色 | `有实现 / 有条件实现 / 仅文档可证 / 不适用 / 尚未证实` |
| CM-02 | 项目规则 / 技能加载 | 同上 |
| CM-03 | 资料选择与代码检索 | 同上 |
| CM-04 | 单条工具输出治理 | 同上 |
| CM-05 | 窗口计量与触发 | 同上 |
| CM-06 | 自动 / 手动压缩 | 同上 |
| CM-07 | 摘要 / 裁剪 / 重建 | 同上 |
| CM-08 | 长期记忆 | 同上（无则"不适用"或"未发现默认实现（推断）"） |

**孤项检查**：12 项**全部**须有判定与依据；不得留空、不得用"未找到即不存在"。

## 4. 观察纪律（六条，来自 T03 + 全组纪律）

1. **退出码为准 + 至少一次负例**：入口成功以**退出码**判定，不以 stdout 文字；每项构造 ≥1 个"应判失败"的负例，验证判据**能报错**（防"退出码恒 0、看着通过"陷阱）。
2. **版本双重口径**：运行记录**两行都写**——「实际执行版本（入口自报）」+「研究快照 SHA / 冻结分发包」。两者不一致时，该观测**不得**用于验证基于快照写的结论，差异方向计入**归因限制**。
3. **本机污染登记**：运行前登记是否含第三方扩展/hook/自定义 provider/软链；受污染环境观测**只能作行为样点**，不得当"产品默认"。
4. **UNOBSERVABLE ≠ 没有实现**：`NOT_RUN / UNOBSERVABLE / FAILED` 只表"没跑/不可观测/失败"，**不得**写成"机制不存在"。"能力不存在"必须给三要素：**查的路径 + 凭什么 + 官方怎么说**。
5. **不把源码阅读 / 网页 PASS 当实验通过**：机制实验判据走**检查器**，不靠"模型说它记住了"；手动路径从**真实命令事件**核对。
6. **归因限制必写**：不能控制模型时，须写"观察到的变化可能来自模型而非机制"；单轮 ≤10 分钟、≤20 次工具动作，异常即停。

## 5. 常见坑（本次独立复核发现，重点防范）

| 坑 | 说明 | 正确做法 |
|---|---|---|
| **数值来源错认** | 运行时阈值可能来自**服务端下发的模型元数据**（如 Codex `truncation_policy`），**≠** 源码默认常量 | 观测到的阈值注明"取自模型元数据/配置"，与源码常量分列 |
| **token / 字节 / 字符混用** | `64,000 token` ≠ `64 KiB 字节` ≠ `30,000 字符`；中文下字节与 token 差异大 | 每个数字标单位 + 三类角标 |
| **默认 vs 扩展混淆** | pi 默认无 sub-agents/长期记忆，但**仓库随附**示例扩展与 durable 包含 subagent | 正文写"**默认核心**不含"；"仓库随附示例扩展"另列，不写成"完全没有" |
| **"未找到"当"没有"** | 全仓检索零命中 ≠ 无实现 | 标"未发现默认实现（**推断**）"，给检索路径 + 官方怎么说 |
| **层数当维度** | "六层压缩"式叙事不可证（Claude 实测缩短层=2） | 层数**不是维度**，不按数量比较成熟度 |
| **桩/接口名当已实现** | `todo!()/unimplemented!()`、空实现、Feature 门控默认关 | 实现状态区分"默认/条件/实验/桩/未证实" |
| **新旧快照混用** | 同一段落不混用两份快照证据 | 引用旧结论时注明「基线 <旧SHA>」并核新快照是否仍成立 |
| **自述计数与实际不符** | 自述"25 条"实为 28 条等 | 提交前用命令核计数（`grep -c "结论ID:"`），自述数字与实际一致 |
| **污染环境当默认** | 本机扩展改变请求/摘要 | 登记污染；"默认行为"结论留待干净环境复现（T19） |

## 6. 数据走查（DW-*）最低要求

- 每机制 ≥1 条 `DW-<mechanism>-<n>`：**输入 → 处理顺序 → 前后对照（原样留下/变摘要/移除/落盘）→ 写回 → 找回入口**。
- **可算数字**：给公式 + 代入值 + 结果，标【源码常量】/【演示】/【测试样本】。
- **边界例子**：至少 1 个"到线/不到线""奇数预算差 1""多字节不切断""装不下 break"类边界。
- **失败分支**：分类（超窗/中断/取消/预算耗尽）+ 是否有界 + 副作用是否可回退。

## 7. 过程观察（NOT_RUN 也要合格）

- 每条规程：**命令 + 预期事件 + 判据 + 停止条件**；判据走 T03 检查器。
- **未运行**：写 `NOT_RUN + 确切原因`（缺凭据/需交互 TTY/环境阻塞/统一调度 T19），**不得**留白。
- **已运行**：并列"实际执行版本 / 研究快照 SHA / 是否一致"三字段 + 归因限制 + 污染登记 + 退出码判据。

## 附：2026-10-15 补充纪律（T09R / T10R 教训；适用 T11–T13）

1. **「零命中 / 未发现」类断言**：提交前**必须复跑登记命令并贴真实输出**；交替模式**一律 `grep -E "A|B"`（不带反斜杠）**——BSD BRE 下 `\|` 不生效、ERE 下 `\|` 为字面竖线，**两种写法都会恒 0**；并**用一条已知有命中的对照模式验证命令本身非恒 0**（T11R 实证：S2 登记命令=0 而报告值=34）；检索结果如设上限（`head_limit` 等）**必须显式确认是否被截断**；结论须**限定范围**（写"出货路径内未发现"，不写"全仓零命中"）。
2. **「移除 / 不支持」类结论**：优先引**配置层 `unsupportedIfPresent`** 等硬证据（例：T10 `normalize.ts:333-334`）。
3. **同源 ≠ 零耦合**：分界按「**包是否出货 + 引用关系**」逐条判定，**非**按目录/服务标签后缀二分（T09R P1）。
4. 以上并入全组纪律 D10（`00-管理/交接.md` §4）。
