**样本 A（22,003 字节 ≈ 5,501 token）→ 未触发限长**

- 现象：`cat 公交查询结果.txt` 的输出**完整**进入模型；无任何 `truncated` 标记；模型正确读出**中间第 152/154/155 行**（14:50→15:45、15:20→16:15、15:50→16:45）与头/尾事实。

**样本 B（384,079 字节 ≈ 96,020 token）→ 触发限长**

- 现象：`cat 大输出.txt` 输出被限长。**会话存档中模型实际所见条目**（`custom_tool_call_output`）证据：

  - **中间丢失**：`02000` 行**不在**模型所见条目中（模型也答「看不到 02000」）
  - **截断标记原文**（照抄）：`Warning: truncated output (original token count: 96020)`；包装体 `… original_token_count …`；内联 `…160 tokens truncated…`；另一条 `Warning: truncated output (original token count: 10160)`
- **原文可找回**：完整原始输出（含 `02000`）**保留在同会话存档**（`item_completed` 事件，约 497 KB）；即裁剪**只作用于进请求的副本**，**存档原样保留**——与源码 `C10`（活动历史裁剪只作用于 live 副本、rollout 保存未裁剪原载荷）**一致**；找回**不需重跑工具**。

3. **中间那 4 行（139–144）能否取回**——**E2 的核心检查**（"裁剪后能否取回中间原文"）：取回入口、是否需要重跑工具、重读次数。

**人工比对结论（必写，因 G3 无自动判据）**：检查器只能判「最终方案的约束/复活/完成」三类，判不了「中间原文是否丢」。故本轮须在 A5/B4 判据栏之外**另写一小段人工比对结论**，否则会出现「检查器全绿却没答 E2」。

**因果链（若中间的 15:20 那条不可用班次丢失且不可取回）**：即 **HC-01（16:00 前返校）证据丢失风险**——模型可能误选该班次。此因果链同时为 **E4/E1** 提供线索，须写进结论。

## 规程 4：缓存（Caching，CLI 侧可证部分）

| 项 | 内容 |
|---|---|
| **目的** | 观察 CLI 是否**发缓存键**、是否**回读缓存明细**；**不**试图证明服务端命中率 |
| **命令** | 两次结构相似的运行：`codex exec --cd <合成目录> "<任务A>"`；随后同前缀第二次：`codex exec --cd <合成目录> "<任务A+微调>"`（保持前缀不变） |
| **判据（分层）** | ①CLI 侧可证：请求携带 `prompt_cache_key`、响应 `usage` 里出现 `cached_tokens/cache_write_tokens`；②**服务端不可证**：命中率、TTL、断点——**不得**由本地观察下结论 |
| **记录字段** | 两次运行的 `session_id`；观察到的缓存键（若可抓）；`usage` 中 `cached_input_tokens / cache_write_input_tokens`；`prompt_cache_key_changed` 是否出现；两次请求前缀是否相同 |
| **成功判据** | 能证明「CLI 发了键」与「CLI 认了明细」；**明确写下不能证明命中/TTL** |
| **反例** | 把 API 文档的 `ttl=30m`、显式断点**当成** CLI 已启用 → 违反边界 |
| **停止条件** | 同上；额度受限时只跑最小前置+两次对照即停 |
| **状态** | **NOT_RUN** — 原因：待配额授权（需跑 2 次对照）；服务端命中/TTL 部分属 `UNOBSERVABLE`（本地不可控） |

## 停止条件与安全边界（四规程共用）

1. **单轮上限**：≤10 分钟、≤20 次工具动作；达上限**停止该轮**，记录原因，不自动扩大批次。
2. **异常即停**：重复压缩、无界循环、未知远端结果 → 立即停，保留日志，判因后再决定恢复路径。
3. **数据边界**：仅在独立合成目录运行；不读取内部服务凭据/生产数据；原始日志与公开摘录分开；凭据不写入正文/截图。
4. **归因限制**：不能控制模型时，须说明「观察到的变化可能来自模型而非机制」。
5. **状态词汇（任务书 §3.2）**：`OBSERVED / NOT_RUN / UNOBSERVABLE / FAILED` 分列，**不与「机制不存在」混用**。
