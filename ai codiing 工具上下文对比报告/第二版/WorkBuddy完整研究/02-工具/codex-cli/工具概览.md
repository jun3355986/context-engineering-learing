## 4. 能力覆盖（一句话版；逐项判定见 `问题与审查.md` §2 十二机制表）

- **请求组装**：`build_prompt` 把 input/tools/base_instructions/output_schema 拼成请求；`WorldState` 承载项目规则与实时状态（`A1/A3`，两快照均成立）。
- **项目规则**：`AGENTS.md` 差分更新 + 发现范围 + 32 KiB 共享字节预算（`A4/A5/A6`，两快照逐字节相同）。
- **窗口计量与触发**：`W×p%（缺省 95）= 整段线`，`min(模型字段 M, 90% 基础线) = 范围线`，两者 OR（`codex-trigger-01/02`，新快照 `context_window.rs` 逐字节相同）。
- **自动压缩**：轮前 / 轮中 / 轮后三个时机；本地路径与远端 v2 路径（provider 门控，OpenAI/Azure 默认 v2）。
- **手动压缩**：`/compact`（`tasks/compact.rs`，两快照逐字节相同）。
- **保留与重建**：本地路径 20,000 直接保留预算、候选只收真用户消息；远端 v2 共享 64,000 token、单条 AgentMessage ≤ 10,000。
- **持久化 / 恢复**：替换内存历史 + 追加 `CompactedItem` 检查点；恢复=替代历史 + 后缀回放。
- **缓存**：CLI 发 `prompt_cache_key`（默认 session_id）并解析 `cached_tokens/cache_write_tokens`；服务端缓存行为不可由源码核实。
- **长期记忆**：`memories` crate（`write` 后台提取 + `read` 注入），**两快照均存在**（深层语义待专项核验）。
- **子 Agent 交接**：`multi_agents` 机制存在（详见 `问题与审查.md` 十二机制表 CM-09）。
