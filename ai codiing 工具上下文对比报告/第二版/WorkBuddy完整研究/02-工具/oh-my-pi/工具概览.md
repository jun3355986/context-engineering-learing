## 3. 能力覆盖（一句话版；逐项判定见 `问题与审查.md` §2 十二机制表）

- **请求组装与角色**：`buildSessionContext()` 从 **leaf→root 路径**重建 LLM 上下文——有压缩时"**摘要消息在最前 + `firstKeptEntryId` 起的保留段 + 压缩后消息**"，并尊重 `/clear` 的 `reset_boundary`；末尾统一剥离"悬挂 tool_use"与失败/中止的 assistant 轮（`ohmy-assembly-01`）。
- **项目规则 / 技能**：内置上下文文件名 `AGENTS.md/CLAUDE.md/GEMINI.md/copilot-instructions.md`（+ `contextFiles.extra`），多 workspace root 发现并去重；`agentsMdFiles` 有 **200 个文件上限**；技能走**渐进式披露**（`skill://` 按需读，提示词只放摘要）（`ohmy-rule-01/02`）。
- **资料选择与代码检索**：`read/grep/glob` 等按需读取；`read` 支持行范围/分页，`read.defaultLimit` 被夹到 `[1, 3000]`（`ohmy-retrieval-01`）。
- **单条工具输出治理**：两条独立上限 **3000 行 / 50 KiB（51200 字节）**，取先到者；`read/grep` 保头（`truncateHead`），`bash` 保尾（`truncateTail`）；**超限原文落盘为 artifact**（`artifact://<id>`），artifact 上限 **16 MiB**（头 3 MiB + 滚动尾）（`ohmy-trunc-01/02`）。
- **窗口计量与触发**：`resolveThresholdTokens()`——默认 `thresholdTokens=-1`/`thresholdPercent=-1` 时用 **`window − 有效预留`**；**有效预留 = `max(floor(window×0.15), 配置值 ?? 16384)`**；用量取最近有效 assistant 的 `calculateContextTokens(usage)`（剔除服务端编排 token），并由本地存量估算**取大兜底**（`ohmy-trigger-01/02`）。
- **自动 / 手动压缩**：**六条触发路径**——手动 `/compact`、溢出恢复、输出未完成（`length`）恢复、轮后阈值、**轮中阈值**、空闲维护；自动走 **`compaction.methodOrder`（默认 `["remote","snapcompact","handoff","shake","soft"]`）**（`ohmy-compact-01`、`ohmy-trigger-03`）。
- **摘要 / 裁剪 / 重建**：结构化摘要（Goal / Constraints & Preferences / Progress / Key Decisions / Next Steps / Critical Context / Additional Notes + `<files>`），旧摘要经 `<previous-summary>` **增量更新**；切点走在 user/assistant/… 边界、**绝不切在 toolResult**，从最新往回累加到 **`keepRecentTokens`（默认 20000）**；**压缩前先跑工具结果裁剪**（保护最新 40000 token、最小节省 20000 token、<50 token 不裁）；另有 **shake**（落 `artifact://` 的机械省略）与 **snapcompact**（历史渲染成 PNG 位图，无 LLM 调用）两种本地方法（`ohmy-summary-01..04`）。
- **长期记忆**：**有独立长期记忆**——`memory.backend` 默认 **`off`**，可选 `local`（本地 rollout 摘要管线，注入 "Memory Guidance"，注入上限 5000 token）/`hindsight`（远程向量服务）/`mnemopi`（本地 SQLite）/`sharpshooter`（项目决策文件）（`ohmy-memory-01`）。
- **子 Agent 交接**：**支持**——`task` 工具按 agent 定义（自带 `systemPrompt`）+ `task`/`solutionSpace` 生成**独立子会话**；支持 isolation、batch、`outputSchema`；单 agent 输出上限 **500,000 字节 / 5000 行**；有递归深度上限（`ohmy-cm09-01`）。
- **保存 / fork / 恢复**：会话是**只追加 JSONL 条目日志**（`id`/`parentId` 成树）；压缩**只追加 `CompactionEntry`、不删原始条目**；恢复/重建走 `buildSessionContext`（**持久化断点路线 B**），并支持 provider 原生回放载荷（OpenAI remote / Anthropic native）；`/tree`、`/branch` 是**同文件叶子移动**，`createBranchedSession` 才另写新文件（`ohmy-persist-01`、`ohmy-recover-01`、`ohmy-fork-01`）。
- **错误与副作用**：溢出**不进**通用重试、走"先升级模型→再压缩"；输出未完成的连续恢复**上限 3 次**；通用重试 `retry.maxRetries` 默认 **10**、退避 500ms→8000ms（带抖动）；失败 assistant 从**运行时上下文**移除但**日志仍保留**并标 `retryRecovery`（`ohmy-fail-01/02`）。
- **缓存及总成本**：**缓存预热器自 pi 移植**（在 TTL 的 90% 处重放、节省下限 $0.05、streaming/idle 两阶段、60/30 分钟上限）；handoff 侧请求**复用实时 prompt-cache key** 以对齐前缀（`ohmy-cache-01`）。

## 4. "默认" vs "装扩展/开配置以后"（本任务硬要求 A）

> 扩展点机制：oh-my-pi 有**扩展（extensions）**与**钩子（hooks）**两层；钩子事件含 `session_before_compact` / `session.compacting` / `session_compact` / `session_before_tree` / `session_tree` / `context` / `before_agent_start` / `tool_call` / `tool_result` 等（`ohmy-ext-01`）。**默认分发（未装扩展、未开配置）不含下列扩展态/条件态行为。**

| 维度 | 默认（omp 本体） | 条件/扩展态能改什么 | 证据 |
|---|---|---|---|
| 压缩方法 | `methodOrder=["remote","snapcompact","handoff","shake","soft"]`（按可用性逐级回退） | 可改顺序、可增删方法；扩展可 `cancel` 或提供自定义压缩载荷 | `ohmy-compact-01`、`ohmy-ext-01` |
| 摘要内容/格式 | 内置结构化摘要 + `<files>` 文件清单 | `session.compacting` 可覆盖 prompt/注入 context/写 `preserveData`；`session_before_compact` 可取消或整体替换 | `ohmy-summary-01`、`ohmy-ext-01` |
| 记忆 | **`memory.backend=off`（默认无记忆）** | 设 `local/hindsight/mnemopi/sharpshooter` 后启用；`learn`/`recall`/`retain` 等工具随之可用 | `ohmy-memory-01` |
| 子 Agent | **内置 `task` 工具（默认可用）**；`task.isolation.enabled` 默认 **false**、`task.batch` 默认 **true**、`task.structured` 默认 **false** | agent 定义可发现/自定义；`spawns`/`tools`/`model`/`prewalk`/`advisor` 可配 | `ohmy-cm09-01` |
| 实验性上下文管理 | `compaction.experimentalContextManagement=false` | 开启后改用"持久笔记 + 可检索原文历史"（`context_notes`/`new_context`/`history://current/full`），**并恢复模型可见的原文找回** | `ohmy-summary-04`、`ohmy-recover-01` |
| 请求消息 | 系统提示词模板 + 投影消息 + 工具声明 | `context` 钩子可改写每次 LLM 调用前的消息；`before_agent_start` 可改提示词/注入消息 | `ohmy-ext-01` |
| 子 Agent 上下文 | 子会话**自带 systemPrompt + task**，不继承父对话历史 | 扩展可自定义 agent 定义与工具集 | `ohmy-cm09-01` |

**一句话边界**：oh-my-pi 的"默认"已是**重内核**（含子代理、压缩方法链、可选记忆、LSP/DAP）；与 pi 的"最小内核"是**默认行为差异**，不是同源即相同。凡"配置打开才生效"的能力（记忆、实验性上下文管理），报告中必须分列。

## 5. 为 T06（pi）预留的可比字段——oh-my-pi 侧独立结论（硬要求 B）

> 逐字段给出 **oh-my-pi 侧独立证据**（不照抄 pi 结论）；完整对照表见 `问题与审查.md` §5。

| 可比字段 | oh-my-pi（本包结论ID） |
|---|---|
| 整理触发 | `resolveThresholdTokens`：默认 `window − max(floor(window×0.15), 16384)`（200K 窗口→**170,000**）；六条触发路径（含轮中/空闲）（`ohmy-trigger-01/03`） |
| 保留预算 | **独立保留预算 `keepRecentTokens=20000`**；另有压缩前**工具裁剪预算**（保护 40000 token / 最小节省 20000）；切点不绝于 `toolResult`（`ohmy-summary-02/03`） |
| 工具输出 | **3000 行 / 50 KiB 先到者**；head/tail 分流；**超限落 artifact 磁盘**（`artifact://<id>`，16 MiB 上限）；单行列上限 512 字节（`ohmy-trunc-01/02`） |
| 恢复方式 | **持久化断点**：追加 `CompactionEntry`（`summary`+`firstKeptEntryId`），恢复按分支投影重建；原条目仍在文件；并叠加 provider 原生回放（`ohmy-recover-01`） |
| 扩展点 | 事件钩子（`session_before_compact`/`session.compacting`/`session_compact`/`session_before_tree`/`context`/`before_agent_start`…）+ 扩展注册；**默认即含 pi 没有的子代理与记忆**（`ohmy-ext-01`、`ohmy-cm09-01`、`ohmy-memory-01`） |
