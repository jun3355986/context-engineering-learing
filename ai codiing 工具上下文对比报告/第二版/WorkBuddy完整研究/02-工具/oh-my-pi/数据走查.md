# oh-my-pi · 数据走查

> 每条 `DW-<mechanism>-<n>` 走完 **输入 → 处理顺序 → 前后对照（原样留下/变摘要/移除/落盘）→ 写回 → 找回入口**。
> **数字角标**：【源码常量】=快照代码里的常量；【演示】=按公式代入的换算；【测试样本】=合成输入。单位一律标 token / 字节 / 行。
> **边界例子**：每条至少给一个"到线/不到线""奇数差 1""多字节不切断""装不下 break"类。
> **失败分支**：分类（超窗/中断/取消/预算耗尽）+ 是否有界 + 副作用是否可回退。

## DW-assembly-01 · 请求组装（CM-01）

- **输入**【测试样本】：分支路径 = `hdr, user, assistant, toolResult, user, assistant, toolResult, toolResult, assistant, toolResult`；最新 `compaction` 在索引 10，`firstKeptEntryId` 指向索引 4 的 user。
- **处理顺序**【源码】：`buildSessionContext` 回溯路径 → 记最新 compaction → 发射 `[summary] + path[4..9] + path[11..]` → 剥离悬挂 tool_use → 丢弃 error/aborted assistant。
- **前后对照**：
  - **原样留下**：索引 4–9 的保留段与压缩后条目。
  - **变摘要**：索引 1–3 的旧历史 → 一条 `compactionSummary` 消息。
  - **移除**：`compaction` 记录本身不进入消息；失败/中止 assistant 轮被丢弃。
  - **落盘**：无（原始条目仍在 JSONL）。
- **写回**：`agent.replaceMessages(context.messages)`。
- **找回入口**：原始条目在会话 JSONL；实验态经 `history://current/full`（`read`/`grep`）。
- **边界**：若 `firstKeptEntryId` 落在 **toolResult**（异常文件）→ `findIndex` 找不到合法保留起点则 `retainedStart=-1`，不发射保留段（不会把 toolResult 当轮首）。
- **失败分支**：路径含环 → 遇重复 id 即停（有界）；`/clear` 边界晚于压缩 → 只发射 reset 之后（有界）。

## DW-assembly-02 · 系统提示词前缀（CM-01/CM-12）

- **输入**【测试样本】：两个会话，同模型、不同 cwd。
- **处理**：主模板渲染 → eval prelude guidance → 末尾 `<project-context>`（含上下文文件路径/workspace 树/active repo/session 追加）。
- **前后对照**：**静态前缀相同**（模板部分）；**尾部 project-context 不同**（cwd 相关）。
- **写回**：作为 `Context.systemPrompt` 数组首块。
- **边界**：`NULL_PROMPT=true` → 返回空数组（无提示词）。
- **失败分支**：模板渲染异常 → 若为"发现的"模板则回退内置模板（有界）；准备步骤超时 5000ms → 该步用最小回退并告警（有界）。
- **不能证明**：实际缓存命中率（服务端）。

## DW-rule-01 · 上下文文件发现（CM-02）

- **边界**：`contextFiles.extra` 列内置名（如 `agents.md`）→ 校验报错（防重复加载/绕过按深度遮蔽）。
- **失败分支**：某 root 发现失败 → `.catch(() => [])`，不阻断（有界）。

## DW-retrieval-01 · 按需检索（CM-03）

- **输入**【测试样本】：`read(path, range.startLine..endLine)` 或省略范围。
- **处理**：省略范围时 `requestedLength = read.defaultLimit`，夹到 `[1, DEFAULT_MAX_LINES]`。
- **数字**：`DEFAULT_MAX_LINES = 3000`【源码常量】→ `read.defaultLimit` 上限 3000 行。
- **前后对照**：只读入请求窗口，不整块装填。
- **边界**：请求 5000 行 → 实际最多 3000 行（`Math.min(requestedLength, DEFAULT_MAX_LINES)`）。
- **失败分支**：文件在扫描中变更 → 从字节 0 重扫（有界）。

## DW-trunc-01 · 工具输出限长（CM-04）【含函数级观察】

- **输入**【测试样本】：① 10 行小文本；② 3500 行；③ 单行 60000 ASCII 字节；④ 600 行 CJK（每行 ~190 字节）。
- **处理**：`truncateHead` 先算总量，未到线原样；否则从头逐行累加至超限。
- **数字**【源码常量】：`DEFAULT_MAX_LINES=3000`、`DEFAULT_MAX_BYTES=50*1024=51200`、`DEFAULT_MAX_COLUMN=512`。
- **前后对照**：
  | 输入 | 输出 | 依据 |
  |---|---|---|
  | ① 10 行 | `truncated=undefined`，原样 | OBS 断言 1 |
  | ② 3500 行 | `truncatedBy=lines`，`outputLines=3000`（丢 500 行） | OBS 断言 2 |
  | ③ 60000 字节单行 | `truncatedBy=bytes`，`firstLineExceedsLimit=true`，`content=""` | OBS 断言 3 |
  | ④ 600 行 CJK | `truncatedBy=bytes`，输出 51174 字节，合法 UTF-8，**不切半字** | OBS 断言 4 |
- **写回**：截断后的 `content` 进工具结果消息；完整原文**落盘** artifact。
- **找回入口**：`artifact://<id>`（read）；落盘上限 16 MiB【源码常量】。
- **边界（奇数差 1）**：单行 51201 字节 > 51200 → 首行超限返回空（到线判据是**严格 > maxBytes**，51200 本身放行）。
- **多字节不切断**：④ 输出 51174 ≤ 51200 且 `Buffer.from(content,"utf-8").toString()===content`（观察断言）。
- **失败分支**：artifact 写入失败 → 记 `artifactError`，不抛（有界）；artifact 触顶 16 MiB → 中间省略写 `[ARTIFACT TRUNCATED: …]`（有界）。

## DW-trigger-01 · 阈值线（CM-05）

- **输入**【演示】：`contextWindow=200000`，默认 settings（`thresholdPercent=-1`,`thresholdTokens=-1`,`reserveTokens=undefined`）。
- **处理**：`resolveThresholdTokens` → `promptBudgetTokens = window − resolveBudgetReserveTokens`。
- **数字**【源码常量 + 演示】：
  - `DEFAULT_RESERVE_TOKENS = 16384`【源码常量】
  - `effectiveReserveTokens = max(floor(200000×0.15), 16384) = max(30000, 16384) = 30000`【演示】
  - `threshold = 200000 − 30000 = 170000`【演示】
  - **pi 对照**：pi 预留固定 16384 → `200000 − 16384 = 183616`。
- **边界（到线/不到线）**：`contextTokens=170000` **不**触发（判据是严格 `>`）；`170001` 触发。
- **1M 窗口**【演示】：`reserve=max(150000,16384)=150000` → `threshold=850000`。
- **小窗口回退 / W−1 上限**（`resolveBudgetReserveTokens` L336-345、`promptBudgetTokens` L380-382）：默认预留对小窗口不可用（`reserve ≥ W − floor(W×0.15)`）或超出窗口时，改用比例预留 `max(1, floor(W×0.15))`；`promptBudgetTokens` 取 `min(W−1, W − reserve)`，故阈值永不等于整窗。常规 200K 窗口不触发该回退，`170,000` 不受影响。
- **写回**：无（纯判定）。
- **失败分支**：`contextWindow<=0` 或 `enabled=false` → 不触发（有界）。

## DW-fail-01 · 溢出与未完成恢复（CM-11）

- **输入**【测试样本】：① 同模型 assistant 报上下文溢出；② `stopReason=length` 且无文本无工具调用。
- **处理**：① 先 `#promoteContextModel()`（升级更大窗口）→ 失败则方法链压缩重试；② 阈值下且无产出 → 直接重试不压缩；阈值上 → 压缩重试；连续无产出恢复**上限 3 次**。
- **数字**【源码常量】：连续无产出恢复上限 `3`。
- **前后对照**：失败的 assistant 从运行时移除；原条目在日志保留。
- **边界**：有产出（文本或工具调用）的截断轮 → **保留**并给输出上限告警（压缩无法提高输出上限）。
- **失败分支**：升级不可用 + 压缩无进展 → 阻止自动续跑并告警（有界，不重复提交同一超大请求）。

## DW-fail-02 · 通用重试（CM-11）

- **输入**【测试样本】：provider 返回 429。
- **处理**：分类为可重试 → 移除失败 assistant → 退避 `min(500×2^(n-1),8000)×(75–100%)` → `agent.continue()`。
- **数字**【源码常量】：`maxRetries=10`、`baseDelayMs=500`、`maxDelayMs=300000`；退避序列 500/1000/2000/4000/8000…ms。
- **前后对照**：**移除（运行时）**：失败 assistant；**保留（日志）**：error 条目 + 成功后标 `retryRecovery`（recovered/superseded），重建 LLM 上下文时排除。
- **边界**：重试产生**重复副作用**风险——仅当"每个已发出的工具调用都有 `details.executed===false` 的合成结果"才允许重放；否则保留已发生副作用不重放。
- **失败分支**：预算耗尽且无回退模型 → `auto_retry_end{success:false}` 终态（有界）。

## DW-cache-01 · 缓存预热（CM-12）

- **输入**【测试样本】：某模型声明 5 分钟 prompt-cache 生命周期，run 仍在活跃。
- **处理**：在 TTL 的 90%（=4.5 分钟，且至少留 10s）安排重放；预计节省 ≥$0.05 才发。
- **数字**【源码常量】：`getCacheWarmingDelayMs = min(ttl×0.9, ttl−10000)`；`CACHE_WARMING_MINIMUM_EXPECTED_SAVINGS=0.05`；`MAX_WARMING_AGE_MS=60min`、`MAX_IDLE_WARMING_AGE_MS=30min`；`IDLE_CONTINUATION_PROBABILITY=0.15`。
- **前后对照**：**原样留下**：缓存条目被重放保活；**移除**：无（不改历史）。
- **边界**：TTL ≤10000ms → 不预热（`undefined`）。
- **失败分支**：重放 miss/error/aborted → 停止预热（有界）；仅对"目录声明了该保留档 TTL"的模型预热。
- **不能证明**：服务端实际命中率与省钱效果（UNOBSERVABLE）。

## DW-ext-01 · 扩展点（CM-…）

- **输入**【测试样本】：扩展监听 `session_before_compact` 返回 `{cancel:true}`。
- **处理**：压缩在生成摘要前被取消；无新 `CompactionEntry`。
- **前后对照**：**移除**：本次压缩；**保留**：历史不变。
- **边界**：`session.compacting` 返回 `preserveData` → 写入 `CompactionEntry.preserveData`（条件态）。
- **失败分支**：hook 抛错 → 视为压缩失败，不追加条目（有界）。
