# deepseek-harness · 数据走查（DW-*）

> **格式**：输入 → 处理顺序 → 前后对照（原样留下 / 变摘要 / 移除 / 落盘）→ 写回 → 找回入口。
> **可算数字**：给公式 + 代入值 + 结果，标【源码常量】/【演示】/【测试样本】。
> **边界例子**：至少 1 个"到线/不到线""奇数预算差 1""多字节不切断""装不下 break"。
> **失败分支**：分类（超窗/中断/取消/预算耗尽）+ 是否有界 + 副作用是否可回退。
> 数字若来自 **模型元数据/适配器声明**（如 1,000,000 窗口），**明确标注**，不与源码常量混列。

## DW-assembly-01 · 一次请求装了什么（CM-01）

**输入**：会话历史含 `system/message`(节点0) → `user/message` → `assistant/message`(含 tool-call) → `tool/result` → `user/message`。

**处理顺序**：`agent-loop` 取 `header.config` + `deriveMessages()`（投影 surface）+ `header.tools`。

**前后对照**：

| 内容 | 去向 |
|---|---|
| `system/message`（非空，最新） | **原样**成为有效提示词（不是请求的 `system` 字段） |
| 历史消息 | **原样**进入 `messages` |
| 工具 schema | **原样**进入 `header.tools`；工具名相对前一 header 的增删 → **另发** `developer/message` |
| `compaction/*`、`command/*`、`llm/retry` | **移除**（log-only，不进 surface） |

**写回**：请求即组装，不写状态；`request/header` 仅在首个请求/变更信封/替换后/恢复时记日志（`agent-loop/README#L93`）。

**找回入口**：`deriveMessages()` 从日志投影；原始事件全在追加式日志。

**边界**：空渲染 → 清空所有提示词节点（无提示词）；能力路由下变更提示词 → 合并到节点0（前缀从该点起变化）。

## DW-rule-01 · AGENTS.md + 技能目录注入（CM-02）

**输入**：`~/.dsh/AGENTS.md`(2 KiB) + `项目/AGENTS.md`(50 KiB) + `项目/packages/app/AGENTS.md`(20 KiB)；技能 3 个（描述各 ≤ 500 字符）。

**处理顺序**：① 首个 eligible `agent/pre-step` 组合 baseline（用户全局→项目链，宽→窄）；② 按 `maxBytes` 渲染；③ 技能目录在首个请求前另发一条 user 消息。

**前后对照**（`maxBytes`=65,536【源码常量】）：

| 内容 | 去向 |
|---|---|
| `~/.dsh/AGENTS.md`(2 KiB) + 项目 AGENTS.md(50 KiB) + app/AGENTS.md(20 KiB) = **72 KiB** | 总预算 64 KiB **装不下** → **先丢最宽泛的**，再截断最具体文件；发 "Workspace instruction budget …" 通知 |
| 去重（同内容 `CLAUDE.md` 与 `AGENTS.md`） | **移除**（按内容摘要去重） |
| 技能**目录**（名字+截断描述） | 变"目录条目"（渐进式披露）；**正文不注入**，由 `skill` 工具按需加载 |
| 变更/消失的指令文件 | 追加 `Updated instructions…` / `Instructions removed…` |

**可算数字**：`渲染字节 ≤ maxBytes`；文件 "app/AGENTS.md" 是**最具体**者 → 只在丢掉宽泛文件后仍超才被**截断**。代入：丢掉 50 KiB 项目文件后 = 2+20 = 22 KiB ≤ 64 KiB → **无需截断**（【演示】按字节计）。

**写回**：注入为 durable `user/message`（含 typed source + change list），随会话 replay/compact/resume。

**找回入口**：磁盘上的 `AGENTS.md`/`CLAUDE.md`；`skill` 工具按名读全文。

**失败分支**：权限/IO 失败 → **停止发现并报错**（不选祖先项目）；不可读候选 → 该组保留 last-good（不误报删除）。

## DW-retrieval-01 · 按需检索（CM-03）

**输入**：用户问"改接口筛选条件，兼容旧客户端"。

**处理顺序**：模型先 `glob`/`grep` 定位 → 再 `read`（分页）→ 需要时 `read` 更多页。`@file` 提及只给**路径候选**。

**前后对照**：

| 内容 | 去向 |
|---|---|
| 相关文件片段（模型主动读的） | **原样**进 tool 结果 → 消息列表 |
| 未读文件 | **不进入**请求（按需读入） |
| `@file` 提及 | **只**插入 `@path` 普通文本（**不附内容**） |

**写回**：读结果作为 `tool/result` 进入 surface。

**找回入口**：`read`/`grep`/`glob`。

**边界**：`read` 一次最多 `readLimit`=2000 行【源码常量】；超 `readMaxBytes`=51200 字节【源码常量】以 capped footer 结束 → 模型须分页。

## DW-retrieval-02 · 跨会话引用快照（CM-03/CM-08 边界）

**输入**：用户 `@[label](dsh-session:<id>)` 提及另一会话。

**处理顺序**：服务把提及改写为 `@label` → 紧接着追加**第二条 user 消息** `## Referenced sessions`（有界只读快照 + 不可信背景警告）。

**前后对照**（【演示】W=1,000,000）：

| 内容 | 去向 |
|---|---|
| 被引用会话消息 | 保留为**有界快照**（每源字节预算）；旧非检查点消息**先被丢弃**，再缩短保留文本 |
| 超出预算 | **落盘**（若挂 spill 后端）+ 省略通知（`omittedMessages`/`omittedBytes` + locator） |
| 固定警告 | 原样（禁止执行快照内指令/权限声明/工具请求） |

**可算数字**：自动预算 = `max(65536, floor(contextWindow × 4 × referenceContextFraction))` 字节/源；`referenceContextFraction`=0.2【源码常量】。代入 W=1,000,000：`max(65536, floor(1,000,000×4×0.2)) = max(65536, 800,000) = 800,000 字节/源`（【演示】）。

**写回**：durable user 消息。

**边界**：`maxReferences` 默认 **3**（不得超 3）【源码常量】；无路由/容量时退化为 64 KiB。

## DW-trunc-01 · 工具自带输出上限（CM-04 第 1 层）

**输入**：`read` 一个 5000 行 / 300 KiB 的日志文件。

**处理顺序**：`read` 应用 `readLimit`(2000 行) / `readMaxLineLength`(2000 字符/行) / `readMaxBytes`(51200 字节)【源码常量】。

**前后对照**：

| 内容 | 去向 |
|---|---|
| 前 2000 行（≤51200 字节） | **原样**进结果 + 分页 footer |
| 超 51200 字节部分 | **移除**（capped footer 提示） |
| 超 2000 字符的行 | **截断** |

**可算数字**：单次 `read` 结果 ≤ min(2000 行, 51200 字节)；5000 行 → 至少 3 次分页（【演示】）。

**写回**：`tool/result` 进 surface，直到压缩遮蔽。

**边界**：`readStreamMinSize`=10485760 字节【源码常量】——≥此值**流式**读，不整体载入内存。

**失败分支**：`limit > readLimit` → 稳定错误 `limit must be less than or equal to <max>`。

## DW-trunc-02 · 工具输出落盘（CM-04 第 2 层，spill）

**输入**：`web_fetch` 返回 300 KB 文本；`maxInlineTokens`=12500【源码常量，默认装配】。

**处理顺序**：`tools/post-execute` 的 `spill-policy` 计算估计 token；超预算 → 保留头/尾 + 省略通知 + **全文落 `spill-local`**。

**前后对照**：

| 内容 | 去向 |
|---|---|
| 头/尾预览（各约一半剩余预算） | **原样**进结果 |
| 中间被省部分 | **落盘**（文件路径进通知） |
| 通知 | 变"省略通知"（省 N 字节 + 完整路径 + `read`/`grep` 指引） |
| 若存储失败 | **原文照旧可见**（best-effort，不替换成不可读路径） |

**可算数字**：估计用同一 4 字符/token 启发式【源码常量】；300 KB ≈ 300000/4 = 75,000 token ≫ 12500 → 触发落盘（【演示】）。

**找回入口**：通知中的路径 + `read`（offset/limit）或 `grep`。

**边界**：`maxInlineTokens` **省略即关闭**；负/小数 → 加载失败。

## DW-trunc-03 · 压缩前工具剪裁（CM-04 第 3 层，pruner）

**输入**：一条 20,000 字符的工具结果文本；`thresholdChars/headChars/tailChars`=8192/4096/1024【源码常量】。

**处理顺序**：**仅当压缩触发后**，`pruneSession` 按 **Unicode code point** 计长，超阈值 → 替换为 head+marker+tail。

**前后对照**：

| 内容 | 去向 |
|---|---|
| 前 4096 字符 | **原样**留下 |
| 中段（4096..18976） | **移除**，替换为 `PRUNE_MARKER` |
| 后 1024 字符 | **原样**留下 |
| 原始事件 | **保留在日志**（替换事件经 `sourceEventSeqs` 引用） |

**可算数字**：`emitted = headChars + codePointLength(marker) + tailChars`；`marker` = `\n\n[... tool result middle pruned ...]\n\n`（**39 个 code point**，实测见下）。代入：`4096 + 39 + 1024 = 5159 ≤ 8192`（【源码常量】+【演示】）——**配置合法性判据**（`config.ts#L55-63`）。
> **边界（多字节不切断）**：按 code point 切，`Array.from(text).length` 计长——**不劈 UTF-16 代理对**（emoji 不裂）；但**可能切字素簇**（官方 README 明示）。
> **边界（低于压力不触碰）**：低于阈值时 pruner **从不运行**（README "a below-pressure conversation is never touched"）。

**写回**：追加替换 `tool/result` + 前置 `compaction/prune` 影子定价事件。

**找回入口**：原事件 `originalSeq`（日志）。

**失败分支**：会话拒绝替换 → 该次**同步失败**，**已落地的替换保留**（部分副作用，不可回退）。

## DW-trigger-01 · 到线判定与阈值计算（CM-05）

**输入**：`measurement.totalTokens`；适配器声明 `W`；输出预留 `O`；`headroomTokens`=65536。

**处理顺序**：`resolveCompactSpec` → `messageBudget = W − O`；`pressureBudget = messageBudget − B`；`threshold = floor(min(W×0.8, pressureBudget))`；`retain = floor(messageBudget×0.16)`（或显式 `retainTokens`）。

**可算数字**（【演示】，W=1,000,000 为**适配器声明值**）：

| 场景 | O | messageBudget | pressureBudget | threshold = floor(min(800000, ·)) | retain |
|---|---|---|---|---|---|
| 无显式 cap | 0 | 1,000,000 | 934,464 | **800,000** | floor(1,000,000×0.16)=**160,000** |
| DeepSeek 默认 cap | 256,000 | 744,000 | 678,464 | **678,464** | floor(744,000×0.16)=**119,040** |

**前后对照**：

| totalTokens | 行为 |
|---|---|
| 799,999（不到线） | **不压缩**（`return null`，不写日志） |
| 800,000（到线） | 触发：先 pruner（可选）→ 重测 → 需要则摘要 |

**边界（奇数预算差 1）**：`floor` 向下取整——`retain` 为奇数时（如 119,041×0.16 的浮点尾）**丢弃小数**，保证 `retain < threshold` 的加载校验（`config.ts#L198-204`）。
**边界（装不下 break）**：`selectCompactableRange` 若 `keepFromIdx <= firstIdx` → **返回 `null`**（无可安全压缩范围，不写任何东西）。

**写回**：判定本身不写；触发后走 DW-summary-02。

**失败分支**：`pressureBudget ≤ 0` 或 `retainTokens ≥ threshold` → 抛 `TargetPressureConfigError`（**目标级配置错误**，自动路径**告警一次并跳过**主动压缩，溢出恢复仍可用）。

## DW-trigger-02 · 启发式计量（CM-05，观察佐证）

**输入**：一条 user 消息含 400 个 ASCII 字符 / 400 个汉字。

**处理顺序**：`estimateMessage` = `estimateContent(blocks) + ROLE_OVERHEAD`；text 块 = `ceil(len/4)+4`。

**可算数字**（**OBS-dsh-meter-01 实测**，出货代码函数级执行）：

| 输入 | 结果 | 公式核对 |
|---|---|---|
| 400 ASCII 字符（user） | **108** | ceil(400/4)+4+4 = 100+4+4 = 108 ✓ |
| 400 汉字（user） | **108** | 同 ASCII（**即 400 汉字 ≈ 100 token → 低估**） |
| 400 字符（system） | **104** | ceil(400/4)+4 = 100+4 = 104（system 无 per-block 开销） |
| `estimateToolsTokens(undefined)` | **0** | 无工具 |

**前后对照**：计量结果仅用于**触发判定/占用显示**，**不改内容**。
**边界**：**CJK/JSON Schema 低估**（官方 Dev Note 自述）；image 块按结构 JSON 估（route 定价另计）。

## DW-compact-01 · 自动压缩（CM-06）

**输入**：`agent/pre-step`，`totalTokens ≥ threshold`。

**处理顺序**：见 `源码导读.md` §1 伪代码（pruner → 重测 → 选范围 → 事务）。

**前后对照**：

| 内容 | 去向 |
|---|---|
| 被选中的旧范围（平衡边界，不含节点0） | **变摘要**（替换为一条 user 检查点） |
| 最近尾部（`retainTokens` 内） | **原样**留下 |
| 系统提示词/工具/前缀 | **不动**（"cannot reduce the system prompt, tools, or session prefix"） |
| 不可分单元（单个巨大 tool call） | **不能**被切（保留，可能仍超预算） |

**写回**：`compaction/start` → `compaction/summary` → 替换 `user/message` → `compaction/end`。

**失败分支**：
- **超窗**：走 `agent/request-error` 溢出恢复（绕过阈值，一次最大削减）；
- **取消/中断**：抛精确 abort reason，**取消始终优先**；
- **预算耗尽**：`compactionRetries`(=1) 次后仍超 → **抛错**（有界）；
- **副作用**：pruner 若已落地，**不可回退**（保留持久进展）。

## DW-compact-02 · 手动 `/compact`（CM-06）

**输入**：空闲会话，用户输入 `/compact`。

**处理顺序**：`command-compact` → `compactNow()` → 预留空闲准入 → `turn:null` 独立 bracket → 选范围（`retainTokens=0`，**低于阈值也削**）→ 事务 → flush。

**前后对照**：同 DW-compact-01；**命令生命周期（`command/run`/`command/done`）不进模型历史**。

**写回**：成功后 `command/done.sourceEventSeq` 指向 `compaction/summary`。

**失败分支**：忙 → `busy`（不排队）；历史变更 → `changed`；无有用摘要 → `summary`；持久化失败 → `persistence`；取消 → `Compaction cancelled.`。

## DW-summary-01 · 摘要调用装了什么（CM-07）

**输入**：被遮蔽段（如 30 条消息，route 价 200,000 token）。

**处理顺序**：`buildSummarizationInput` 拼 `[system头, ...被遮蔽段消息]` + `header.tools` → `ctx.llm.stream()` 追加**尾部指令**。

**前后对照**：

| 内容 | 去向 |
|---|---|
| system 头 + 工具 + 被遮蔽段 | **原样**回放（前缀，可复用缓存） |
| 尾部指令 | 新增（唯一未缓存部分） |
| 模型输出 reasoning / tool-call | **移除**（只取 text） |
| 图像输出 | **报错** `UNSUPPORTED_CONTENT`（不静默消失） |

**可算数字**：`maxTokens` 默认 = `headroomTokens` = **65536**（【源码常量】）——摘要输出上限；`purpose:'compaction'`。

**写回**：仅返回文本进检查点。

**失败分支**：finish=`error/aborted` → 抛；finish=`max-tokens` → 抛 `MAX_TOKENS`（**不完整检查点**）。

## DW-summary-02 · 检查点与收缩校验（CM-07）

**输入**：摘要文本块。

**处理顺序**：`frameSummary`（preamble + `<compacted-summary>` + 文本 + `</compacted-summary>`）→ `estimateMessage` → 与 `shadowedRouteTokenCount` 比较。

| 内容 | 去向 |
|---|---|

**写回**：`surfaceOp:{op:'replace', startSeq, endSeq}` + `sourceEventSeqs`。

**找回入口**：`shadowedSeqs` 指向的原事件（日志）。

## DW-cm09-01 · 子 Agent 交接（CM-09）

**输入**：主 Agent 调 `subagent`(provider=spawn) 做一项隔离任务。

**处理顺序**：`startActivation` 预留子身份+容量 → 建**独立子会话** → 子跑完 → 结算 → 父收 `delivery:'parent'` 通知。

**前后对照**：

| 内容 | 去向 |
|---|---|
| 父的消息列表 | **不**继承给全新子（`spawn`）；`fork` 以父**已完成历史**为种子 |
| 子的最终文本块 | 变**父级 user 通知**（含 `Structured result: <JSON>`） |
| reasoning / 非文本块 | **移除**（通知不含） |
| 空收尾 | 变 `It left no closing message.` |

**可算数字**：`maxDepth`=1（仅直属子）、`maxActiveSubagents`=8（根父不占槽）【源码常量/默认】。

**写回**：父日志追加 `subagent/catalog` 事实（本地创建时**无论**投递方式）+ 通知消息。

**失败分支**：容量满 → `ACTIVATION_LIMIT_REACHED`（**不排队**）；无 `agents` 服务 → `CONTINUATION_UNAVAILABLE`；缺/换父 → `UNAUTHORIZED`。

## DW-persist-01 · 会话落盘与找回（CM-10）

**输入**：一次多步 turn。

**处理顺序**：`session-persistence-jsonl` 按批 append + `fsync`（默认 zstd 帧）；`session-checkpoint-policy` 在请求前/工具副作用前 flush。

**前后对照**：

| 内容 | 去向 |
|---|---|
| 每条 durable 事件 | **落盘**（追加，永不改写） |
| `assistant/message` 的流 | **嵌入**为紧凑定时流（fork/resume/telemetry 派生） |
| `assistant/attempt`（失败/重试/取消） | **落盘**但**不进模型历史** |
| `compaction/*` | **落盘**（log-only） |

**写回**：文件系统（`<root>/--<cwd>--/<id>/session.vN.jsonl[.zstd]`）。

**找回入口**：`resume`；`shadowedSeqs` 指向原事件；**无删除 API**。

**边界**：`compression` 默认 `zstd`（不可直接逐行读）；`none` 才是裸行。

## DW-persist-02 · 语义检查点（CM-10/CM-11）

**输入**：即将发起模型请求 / 即将执行顶层工具。

**处理顺序**：`session-checkpoint-policy` 先 flush；**写不成功则不跑**。

**前后对照**：无内容变换；**只决定"是否允许继续"**。

**写回**：flush 到后端。

**失败分支**：flush 失败 → **fail-closed**（适配器/工具体不运行）；无配置、不加提示词。

## DW-persist-03 · 崩溃修复（CM-10/CM-11）

**输入**：进程在"已记录 tool/call 但未落 result"处被杀。

**处理顺序**：重开 → 不完整尾行丢弃 / 撕裂帧取完整记录 → agent 层补错误结果。

**前后对照**：

| 内容 | 去向 |
|---|---|
| committed 前缀 | **原样**保留 |
| 不完整尾行 | **移除** |
| 撕裂 zstd 帧 | 只取**完整解出的** JSONL 记录 |
| 未答 tool/call（有开始记录） | 补 `TOOL_OUTCOME_UNKNOWN`（"outcome is unknown"，只允许重试只读/幂等） |
| 无开始记录的调用 | 补 `TOOL_NOT_STARTED` |

**可算数字**：无。
**失败分支**：完整 committed 帧校验/解压/结构失败 → **判损坏**（不静默截断）；retired PTC 标签/`request/header.header.system` → **拒绝该文件**。

## DW-fail-01 · 模型请求重试（CM-11）

**输入**：一次模型请求返回 `RATE_LIMIT`。

**处理顺序**：`llm-retry` 检查码在 eligible 集且预算未耗尽 → 算延迟（provider `Retry-After` 或本地退避）→ append `llm/retry` → 等待 → append `llm/retry-started` → 返回 `{kind:'retry'}`。

**前后对照**：

| 内容 | 去向 |
|---|---|
| `llm/retry`/`llm/retry-started` | **落盘但不进模型历史** |
| 失败的部分输出 | **不进** derived messages |
| 重试请求 | **同一 open turn** 内用**同一 durable 历史**重建 |

**可算数字**：normal 默认 **5 次**，退避 500ms–10s + 10% 抖动【源码常量】；每次重试 = **新的计费请求**（可能重复输入计费）。
**失败分支**：预算耗尽/码不在集合 → 交给下游；always 模式 → 无上限，仅 success/cancel/disposal 停。

## DW-fail-02 · 压缩失败分类（CM-11）

**输入**：压缩期间发生各类失败。

**处理顺序**：事务 `try/catch` → 记 `failure{stage}` → **恰一次** `compaction/end`（带 error）。

**前后对照**：

| 情况 | 结果 |
|---|---|
| 摘要失败 | `ManualCompactionError('summary')`；失败尝试**已持久化**，**不写**摘要替换 |
| 历史变更 | `'changed'`；同上 |
| 提交阶段失败 | `'commit'`（**可能已部分变更**） |
| flush 失败 | `'persistence'`（内存 bracket 已关，flush 失败） |
| 取消 | 抛精确 abort reason（**取消优先**） |
| 自动路径失败 | **warning + 继续本轮**（不阻断） |

**可算数字**：`compactionRetries`=1 → 最多 **2** 次尝试后抛错（有界）。
**失败分支**：**有界**；副作用（已落地的 pruner 替换）**不可回退**。

## DW-fail-03 · 孤儿锁与稳定性（CM-11）

**输入**：压缩中途崩溃 → 留下未配对 `compaction/start`。

**处理顺序**：下次入口 `inspectCompactionEntryState` 扫日志 → 若存在**活跃**未配对 start → `busy`。

**前后对照**：

| 情况 | 结果 |
|---|---|
| 未配对 start 晚于最新 `session/end-seed` | **阻断**（`busy`） |
| 未配对 start 早于最新 `session/end-seed` | **忽略**（上一生命周期的陈旧证据） |
| 异步摘要后 surface 变了 | **拒绝提交**（`SurfaceChangedError`：whole-surface / selected-span） |

**可算数字**：无。
**失败分支**：收尾失败**刻意留孤儿**（可检测，设计如此）。

## DW-cache-01 · 缓存 usage 与前后缀（CM-12）

**输入**：一次 DeepSeek 调用返回 usage。

**处理顺序**：适配器 `translate` 映射 `cache_read_input_tokens`→`cacheReadTokens`、`cache_creation_input_tokens`→`cacheWriteTokens`；`token-meter` 投影进 `tokenUsage`。

**前后对照**：

| 内容 | 去向 |
|---|---|
| `uncachedInputTokens`/`outputTokens`/`cacheReadTokens`/`cacheWriteTokens` | **分别**记入 usage（**不重复相加**） |
| 压缩替换 | **前缀退化**：从首个被替换 token 起不可复用 |
| `in-history` 路由的提示词变更 | **追加**在缓存历史之后 → 前缀**仍可复用** |

**可算数字**：`totalTokens = inputTokens + outputTokens + cacheReadTokens + cacheWriteTokens`（适配器侧，【源码常量】`translate.ts#L159`）。
**边界**：**未发现** CLI 侧缓存键/断点（S4=1，唯一命中为 Codex 测试样本）；**服务端命中/TTL = UNOBSERVABLE**。
