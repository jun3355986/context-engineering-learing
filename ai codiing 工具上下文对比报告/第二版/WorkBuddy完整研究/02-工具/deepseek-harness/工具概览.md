### 1.1 架构基调（影响全部上下文机制）

`README.md` 明示「**everything-is-a-plugin**」，构建于 [Cordis](https://github.com/cordiverse/cordis)。上下文能力因此**不是单体内核**，而是**可挂载/可替换的插件行**：`token-meter`、`compaction-basic`、`agent-instructions`、`tool-skill`、`spill-policy`、`subagent` 等各为一行。**默认装配**由 bundle `@deepseek-ai/dsh-base`（`packages/bundle/base/cordis.patch.yml`）决定；自定义 profile 逐行替换。

## 3. harness 实现 vs 模型/API 能力分列表（任务书 FB-07 核心纪律）

> **纪律**：凡属**模型侧/服务端**的行为，**不得**当作 harness 实现写入。独立成文见 `harness实现-vs-模型API分列表.md`（逐条 20 项）；下表为速查。

| 维度 | **harness（dsh）实现**（源码/文档可证） | **DeepSeek 模型 / API 能力**（harness 仅**声明/透传/读取**） |
|---|---|---|
| 上下文窗口 | `resolveModelInfo().context.contextWindow` 读取适配器声明的容量；`resolveCompactSpec` 用它算阈值 | **1,000,000 token 窗口**（`llm-deepseek` 目录默认声明；`defaultContextWindow`）——**模型能力** |
| 计量 | **4 字符/token** 固定启发式 + block/role 结构开销（`estimate.ts#L13,16,19`） | **真实分词与计费级 token 数**（服务端）；usage 数值由 provider 返回 |
| 触发 | 阈值公式 `floor(min(W×0.8, W−O−B))`、保留预算、`auto` 开关——**harness 常量** | 阈值取自**适配器声明的窗口与输出预留**；容量来自模型元数据，**非** harness 硬编码 |
| 压缩/摘要 | 事务、8 段摘要指令、`<compacted-summary>` 框架、收缩校验、替换 `user/message`——**harness** | **摘要文本由模型生成**（一次 `ctx.llm.stream()`）；摘要质量/漂移属模型侧 |
| 缓存 | 适配器把 `cache_read_input_tokens`/`cache_creation_input_tokens` **映射为** usage 字段；`systemPromptUpdate:in-history` 的**追加**策略——**harness 侧** | **缓存存储、命中判定、TTL、复用决策 = 服务端**；`cacheReadTokens` 数值 = provider 上报 |
| 溢出 | 分类 `CONTEXT_WINDOW_EXCEEDED` 的**归一化**与恢复流程——**harness** | **溢出的真实判定与措辞 = provider**（"provider wording can change"，适配器维护归一化） |
| 图像 | 离载决策 `image/offload`、占位符文本、Files/内联切换——**harness** | **视觉 token 定价网格**（14px patch、3:1、1024 上限）与上传/删除 = **provider/API** |
| 推理 | `reasoningEffort` 档位映射为 `output_config.effort`——**harness** | **thinking/reasoning 内容本身** = 模型输出；`temperature` 在 thinking 模式被 provider 忽略 |

**一句话**：dsh 的**上下文治理全在 harness**（组装、计量口径、阈值、事务、剪裁、持久化、交接、重试）；**模型/API 只提供**容量、真实分词与计费、缓存存储与命中、溢出判定、视觉定价、推理内容。**"API 支持缓存" ≠ "dsh 默认命中缓存"**——dsh 侧只做**字段映射与前后缀策略**，命中与否**不可观测**。

## 4. 默认 vs 扩展分列（规范 §5"默认 vs 扩展混淆"坑）

> 依据：`packages/bundle/base/cordis.patch.yml`（默认 `dsh-base` 装配，行号见证据卡 `dsh-version-02`）。

| 能力 | **默认核心（dsh-base 装配）** | **扩展 / 非默认** |
|---|---|---|
| 计量 | `token-meter`（无配置，纯启发式） | 无 |
| 压缩 | `compaction-basic`（**默认参数**：0.8 / 65,536 / 0.16 / auto=true）+ `command-compact`（`/compact`）+ `tool-result-pruner`（**8192/4096/1024**）+ `compaction-image-offload` | 自定义 `modelPolicies`、`summarize()` 子类（template/remote 摘要器） |
| 工具输出落盘 | `spill-local` + `spill-policy`（**`maxInlineTokens: 12500`**，`cordis.patch.yml#L414-417`） | 省略 `maxInlineTokens` 即**关闭**落盘 |
| 项目规则 | `agent-instructions`（**`maxBytes: 65536`**，`#L303-306`） | 换 `maxBytes`；profile 可禁用 |
| 技能 | `skill` + `skill-filesystem` + `tool-skill` | `skill-office`、`bundledSkillDir` |
| 子 Agent | `subagent` + `spawn`/`fork` in-process + `tool-subagent`/`-control`/`-fork` | `subagent-acp`/`-codex`/`-claude-code`/`-dsh-sdk`（out-of-process） |
| 持久化 | `session-persistence-jsonl`（默认 **zstd**）+ `session-checkpoint-policy` | `compression:'none'`；其他后端（需实现 `SessionPersistence`） |
| 跨会话检索 | **无** | `session-reference`（opt-in）；`session-search`（实验，**默认关**） |
| **长期记忆** | **无** | `experimental/tool-ralph`（"workspace 即长期记忆"，实验，非默认） |

## 5. 适用范围与边界

- **范围**：以 **CLI（`dsh`）+ `dsh-base` 默认装配**为主研究对象；Web/SDK 仅在与上下文管理相关且有官方证据时旁注（版本表 Q5）。
- **语言无关读法**：机制语义用中文解释；真代码为 TypeScript，`源码导读.md` 先给数据对象与条件，再给函数。
- **可证边界**：本包结论 = **源码（固定 SHA）+ 官方包内文档 + 函数级出货代码观察**；**产品入口端到端未运行**（`NOT_RUN`，本机未安装）。
- **服务端边界**：缓存命中/TTL、真实分词、溢出真实判定、视觉定价 = **UNOBSERVABLE**（不写成"没有实现"）。
- **未决**：连续压缩失真（LQ-09）、中文口径、SP-09 代价项 —— 依赖 T19。
