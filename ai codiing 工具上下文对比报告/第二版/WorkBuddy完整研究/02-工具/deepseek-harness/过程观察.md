## 3. 已运行记录：OBS-dsh-meter-01（token-meter 估算器，函数级）

**目的**：验证 `dsh-trigger-02` 的固定启发式真实数值（4 字符/token + block/role 开销）——这是 CM-05 计量口径的核心常量。

**命令**（逐字，工作目录 = 本包 `证据/`）：

```bash
bun obs-meter-check.ts        # 正例
bun obs-meter-negative.ts     # 负例
```

**脚本**：`证据/obs-meter-check.ts`、`证据/obs-meter-negative.ts`（只读导入快照 `packages/llm/token-meter/src/estimate.ts`，**不修改快照**）。

**预期事件**：正例 4 项全 PASS、退出码 0；负例断言被推翻、退出码 1。

**判据**：**退出码**（不以 stdout 文字为准）。

**实际输出**：

```text
$ bun --version
1.3.9

$ bun obs-meter-check.ts
ROLE_OVERHEAD = 4
PASS  user 400 ASCII 字符: got=108 want=108
PASS  user 400 汉字: got=108 want=108
PASS  system 400 ASCII 字符: got=104 want=104
PASS  estimateToolsTokens(undefined): got=0 want=0
RESULT: ALL PASS
正例 exit=0

$ bun obs-meter-negative.ts
ascii=108 cjk=108 claim(cjk>ascii)=false
NEGATIVE-DETECTED (判据有效：CJK 未更贵)
负例 exit=1
```

**结论**：正例退出码 **0**（4/4 符合预期）；负例退出码 **1**（"CJK 应更贵"的刻意错误主张**被推翻**，证明判据**非恒真**）。→ 出货代码行为与 `estimate.ts#L13,16,19` 常量一致。

**归因限制（必写）**：
- 观察的是**出货代码的纯函数**（估算器），**不涉及模型**，因此**不存在"模型不可控"归因问题**；
- 但**不能**由本观察推断"产品端到端计量 = 该启发式"——产品路径还叠加 provider usage 锚定（`token-meter` README "Provider usage is reused only for an identical canonical envelope"）；本观察**未运行**该锚定路径；
- **CJK 低估**是官方 Dev Note 自述 + 本观察佐证（400 汉字估成 108），但**不能**给出"低估多少倍"的定量结论（真实分词 = 服务端 UNOBSERVABLE）。

**边界（不能外推什么）**：不能外推到**端到端产品默认行为**；不能外推到**计费级 token**；不能外推到**非文本块**的 route 定价。

## 5. T19 复现规程模板（5 步，供后续照做）

> 前提：作者授权安装/凭据；数据用 T03 冻结包（`T03-DATA-TRIP-v1` 或 `-COMPAT-v1`）；判据走 T03 检查器；单轮 ≤10 分钟、≤20 次工具动作。

```bash
# 步骤 1：安装并冻结（记录"实际执行版本"）
npx @deepseek-ai/dsh --version        # 记录入口自报版本（与快照 5719020 分列）
# 步骤 2：独立合成项目 + 显式 home（隔离）
export DSH_HOME=/abs/isolated-dsh-home
# 步骤 3：启动会话，首条消息只放任务目标 + 硬约束（逐字引用数据包 MSG-00x）
dsh --profile headless "<MSG-00x 原文>" 2>&1 | tee <原始日志路径>
# 步骤 4：触发压缩
#   - 自动：喂长工具结果（T03 长日志）到线；或
#   - 手动：/compact（需命令适配器，headless 可能无；Web 客户端有）
# 步骤 5：恢复
#   resume 同一 session_id，先问"现在有效约束有哪些"，用检查器核对
python3 <T03检查器>/check_task.py --package <数据包> --candidate <候选.json>
```

**预期事件**（依本包结论）：到线后出现 `compaction/start`→`compaction/summary`→替换 `user/message`→`compaction/end`；`/compact` 额外有 `command/run`/`command/done`（**不进模型历史**）。

**停止条件**：出现**重复压缩 / 无界循环 / 未知远端结果** → **立即停止该轮**；或达 10 分钟 / 20 动作上限。
