# 证据卡 · 窗口计量与触发（CM-05）

> **这是 LQ-05 / LQ-11 与 C-01 / C-02（Claude 部分）的裁决主战场。** 一级证据（官方文档）+ 二级证据（本地帮助文本）。全部结论标注适用模型/版本条件。

---

```yaml
结论ID: claude-trigger-01
结论: 自动压缩的**窗口**（"上下文达到多满才压缩"）由四个入口决定，优先级从高到低：`CLAUDE_CODE_AUTO_COMPACT_WINDOW`（环境变量）> `--autocompact`（单次启动标志）> `/autocompact`（当前模型，写入 `modelSettings`）> `autoCompactWindow`（设置文件，所有模型）。窗口取值 **100K–1M tokens**，并被**钳制在模型上下文窗口内**；`auto` 表示"该模型调优的窗口"。
性质: 事实
范围: 当前官方文档；`/autocompact` 需 v2.1.221+；`--autocompact` 需 v2.1.221+；`modelSettings` 需 v2.1.251+
实现状态: 默认（无显式设置时用 auto）
来源: ① https://code.claude.com/docs/en/model-config.md（"Set the auto-compact window" 四种方式 + 优先级）；https://code.claude.com/docs/en/env-vars.md（`CLAUDE_CODE_AUTO_COMPACT_WINDOW` 100000–1000000，仅纯整数）；https://code.claude.com/docs/en/settings-reference.md（`autoCompactWindow` 为 `modelSettings` 内字段，100000–1000000 或 "auto"）；② 本地 `claude --help`（2.1.296）：`--autocompact <auto|tokens>  Auto-compact window size (auto, or 100k–1M tokens)`
数据走查: 见 数据走查.md §3（D-06）
运行证据: 分发件/本地行为观察（帮助文本）；**运行未验证**
不能证明: ①`auto` 对各模型的**具体数值**（文档只给个别例外的近似值，见 claude-trigger-03）；②"钳制在模型窗口内"的上限在自定义模型 ID 下如何取值。
冲突裁决: 支持 LQ-11 的**方向**（Claude 侧确有"窗口口径"与"触发口径"两件事），但**否证**其把窗口口径写成"有效窗口 = 原始窗口 − 20,000"这一步（见 U-01）。
核验日期: 2026-10-15
```

```yaml
结论ID: claude-trigger-02
结论: 触发点是一个**占 auto-compact 窗口的百分比**。`CLAUDE_AUTOCOMPACT_PCT_OVERRIDE`（取值 **1–100**）可**调低**触发百分比（如设 `50` 更早压缩），**不能调高**——高于默认百分比的值会被忽略；该变量**仅对"会在模型上下文限制之前压缩"的会话生效**，且**同时作用于主对话与子代理**。
性质: 事实
范围: 当前官方文档；主对话 + 子代理
实现状态: 默认（默认百分比文档未给出）
来源: ① https://code.claude.com/docs/en/env-vars.md（`CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` 条目原文）；https://code.claude.com/docs/en/sub-agents.md（"`CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` applies to subagents as well"）
数据走查: 见 数据走查.md §3（D-07：以 200K 窗口推演百分比触发点）
运行证据: NOT_RUN
不能证明: **默认百分比是多少**——文档**只给可覆盖区间 1–100，未给默认值**。因此"83.5%"**不能**从本轮官方材料直接读出；它只能作为"某次观测到的触发位置"线索（见 claude-trigger-04）。
冲突裁决: **这是 167K/83.5% 关键**——"按窗口百分比触发"这一**口径成立**（有官方 env 支持），但"82–84% 是默认比例"这一**数值不成立/未决**（文档未给默认值，且默认口径是"达到模型上下文上限才压缩"，见 claude-trigger-03）。详见 问题与审查.md V-02。
核验日期: 2026-10-15
```

```yaml
结论ID: claude-trigger-03
结论: **不设** auto-compact 窗口时，默认在**对话达到模型上下文上限**时压缩；文档列出例外：
- Sonnet 4.6 / Opus 4.6（无 extended context）→ 在 **200K 边界**压缩；
- 设 `CLAUDE_CODE_DISABLE_1M_CONTEXT=1` 时，原生 1M 窗口模型 → 在 **200K 边界**压缩；
- 运行原生 1M 窗口的模型（Fable、Sonnet 5 及更高、Haiku 5.5、Opus 4.7 及更高）→ 默认约 **967K tokens** 时压缩；
- Cloud sessions → 接近模型上限时压缩；
- Claude Code 识别不了的模型 ID（如 gateway 别名）→ 按它为该 ID 假定的窗口压缩。
性质: 事实
范围: 当前官方文档；按模型类别分别成立
实现状态: 默认
来源: ① https://code.claude.com/docs/en/model-config.md（"If you don't set an auto-compact window, Claude Code compacts when the conversation reaches the model's context limit, except in these sessions:" 例外表）
数据走查: 见 数据走查.md §3（D-08）
运行证据: NOT_RUN
不能证明: ①"967K"是**近似**（"about 967K"），非精确常量；②200K 边界是**窗口**还是**触发点**（文档用 "compact at the 200K boundary"，语境为窗口口径）；③各模型确切窗口。
冲突裁决: **否证**"Claude 默认在 90%–95% 压缩"这类总括句（C-01）——文档给的是"模型上限"或"约 967K"（对 1M 模型 ≈96.7%），无统一 90–95%。
核验日期: 2026-10-15
```

性质: 事实（示例值）
范围: 官方文档示例；**不代表默认阈值**
实现状态: 示例（文档用来说明 agent 事件字段）
来源: ① https://code.claude.com/docs/en/sub-agents.md（"compact_boundary" 事件示例；"The `preTokens` value shows how many tokens were used before compaction occurred."）
数据走查: 见 数据走查.md §3（D-09：167,189 与 200K 的关系 = 83.6%；与旧报告"167K"量级一致）
运行证据: 文档示例（非本次运行）
不能证明: ①该示例**不是**默认触发点，不能读成"默认 167K"；②示例未注明模型/窗口，无法反推百分比；③本机 transcripts 未出现 `compactMetadata` 事件（见 过程观察.md OBS-04）。
冲突裁决: 提供"167K"这一数值的**唯一一级出处**：它来自官方**示例**（一级证据但性质为示例），而**命令口径**（−13K/−3K）无出处（U-01）。详见 V-02。
核验日期: 2026-10-15
