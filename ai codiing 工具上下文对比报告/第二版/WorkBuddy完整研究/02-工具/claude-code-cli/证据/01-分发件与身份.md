性质: 事实

不能证明: ①**成功**回合的 transcript 行结构与内容（本次无成功回合，只观测到 setup/失败回合）；②行结构的版本稳定性（官方明说格式内部、版本间会变）；③`memory/` 为空是本机初始态还是普遍现象。

结论ID: claude-dist-06
结论: 本轮全部本地观测**在受第三方扩展污染的本机上完成**，须如实登记：① `~/.claude/settings.json` 在 SessionStart/Stop/PostToolUse/UserPromptSubmit/SubagentStop 挂**第三方** `teamai hook-dispatch --tool claude`；② `~/.claude/skills/` 有 **6 个本地技能**（`defuddle`/`json-canvas`/`obsidian-bases`/`obsidian-cli`/`obsidian-markdown`/`teamai`，末者为第三方），**会影响 `skill_listing.skillCount=19` 的解读**（该数不宜当作"官方内置技能数"）；③ `~/.claude/transcripts/ses_*.jsonl` 与官方原生 `~/.claude/projects/*.jsonl` **并存**、**字段集合完全不同**（前者 `content`/`tool_input`/`tool_name`/`tool_output`；后者 `uuid`/`parentUuid`/`sessionId`/`cwd`/`gitBranch`/`version`/`isSidechain`/`attachment`…）→ 前者**非原生格式**；④ `~/.claude/` 另有 `backups/`、`cache/changelog.md`、`downloads/`、`session-env/`。⑤ **未安装第三方插件**：无 `~/.claude/plugins` 目录；`~/.claude.json` 的 `pluginUsage` 仅含 **builtin** 插件（`cc-plugin-agents-md@builtin`、`cc-plugin-telemetry@builtin`、`cc-plugin-plugin-authoring@builtin` 等）。

范围: 本地 CLI 2.1.296；macOS；本机 ~/.claude
实现状态: 环境事实（非 Claude Code 功能）
来源: 分发件/本地行为观察 — `~/.claude/settings.json`；`ls -1 ~/.claude`；对 `transcripts/ses_*.jsonl` 与 `projects/-private-tmp/<session>.jsonl` 分别做 JSON 顶层键去重
