### 规程 P1｜工具输出落盘与预览（→ MECH-claude-工具输出-01；T03 场景 E2）
1. **准备**：在独立合成项目内，用 `head -c` 之类生成三档纯文本：`N ≈ 20,000`、`N ≈ 40,000`、`N ≈ 80 MiB`；或直接用 T03 冻结包（**已校订行号，见 §3bis**）：`长工具结果-测试日志-v1.txt` / `长工具结果-公交查询-v1.txt`（各 **300 行**）。
2. **命令**（逐字记录）：`claude -p --output-format stream-json --model <MODEL> "<要求运行该命令并说明收到的内容>" 2>&1 | tee <日志>`
3. **记录**：①模型消息里出现的字符数；②是否出现文件路径；③路径是否为 `~/.claude/projects/<project>/<session>/tool-results/`；④落盘文件大小；⑤模型能否按"结论行号"取回中间原文。
4. **成功判据**：`20,000` 全量内联；`40,000` 出现路径且预览 ≤2,000 字符；`80 MiB` 落盘被截断（≤64 MiB）；模型能通过路径取回【测试日志 **第 9 行**（计划 42）】与【尾段 **292**（Tests run 42 / Failures 1）、**293**（BUILD FAILURE）、**298**（结论 3 未提交）】。
5. **失败路径变体**：让命令 `exit 1`（非良性命令）且输出 >10,000 字符 → 验证"头尾摘录 + 无路径"。
6. **映射结论**：claude-toolout-01/02/04。

### 规程 P2｜自动压缩触发点（→ MECH-claude-触发-01；T03 场景 E1/E5）
1. **准备**：固定模型（记录名与窗口）；用 T03 数据包消息序列逐步填充至接近窗口。★注意 **Claude 侧无独立"hard limit"文档**，触发观察以 `compact_boundary` 事件为准。
2. **命令**：`claude -p --output-format stream-json --model <MODEL> --autocompact auto ...` 或交互式会话。
3. **记录**：`compactMetadata.trigger`、`preTokens`、当时模型与窗口、压缩后总量、`/context` 前后两帧。
