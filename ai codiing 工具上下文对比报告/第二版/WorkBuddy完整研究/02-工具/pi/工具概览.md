## 3. 能力覆盖（一句话版；逐项判定见 `问题与审查.md` §2 十二机制表）

- **请求组装与角色**：`_installAgentRequestProjection` 把「规范化会话投影 `projection.messages`（compaction 已应用）+ 可执行工具实现 `tools`」拼成请求；系统提示词按**可独立替换的具名 section**（`preamble/tools/rules/docs/project_context/skills/cwd`…）组织（`pi-assembly-01/02`）。
- **项目规则 / 技能**：`AGENTS.override.md → AGENTS.md → CLAUDE.md` 由 agent 目录 + cwd 逐级**向上**发现，排除被 worktree 遮蔽项；技能走**渐进式披露**（提示词只放一句摘要，用时再读手册）（`pi-rule-01/02`）。
- **资料选择与代码检索**：`read/grep/find/ls` 按需读取；`read` 支持 `offset/limit` 分页续读（`pi-retrieval-01`）。
- **单条工具输出治理**：两条独立上限——**2000 行 / 50KB**，取先到者；`read/grep/find/ls` 保头（`truncateHead`），`bash` 保尾（`truncateTail`）；**超限原文落临时文件**，请求里只留预览 + `Full output: <path>`（`pi-trunc-01/02`）。
- **窗口计量与触发**：`shouldCompact = contextTokens > contextWindow − reserveTokens`（`reserveTokens` 默认 **16384**）；用量优先取**最近一条有效 assistant 的 usage**（含 cacheRead/cacheWrite），其后本地 `ceil(chars/4)` 估算（`pi-trigger-01`）。
- **自动 / 手动压缩**：自动三时机——**轮中**（每批工具结果落定、下一次 assistant 之前）、**新用户提示前**、**运行结束后**；手动 `/compact [指令]`（`pi-compact-01/02`）。
- **摘要 / 裁剪 / 重建**：切点走在**用户/助手消息**边界（**绝不切在 toolResult**）；保留 **`keepRecentTokens` 默认 20000** 的近期原文；旧摘要作为 `<previous-summary>` **增量更新**；产物是追加一条 `CompactionEntry{summary, firstKeptEntryId, tokensBefore}`，投影据此重建（`pi-summary-01/02`）。
- **长期记忆**：**默认无独立长期记忆机制**（源码未发现 memories/后台抽取；pi 定位为 minimal）。跨会话"记忆"由 `AGENTS.md`/扩展自行实现（`pi-memory-01`）。
- **子 Agent 交接**：**不适用——pi 刻意不含 sub-agents**（README 明示；源码无 subagent 生成、无交接/分叉协议）（`pi-cm09-01`）。
- **保存 / fork / 恢复**：会话是**追加式 JSONL 树**；压缩**不删原始条目**，只追加 `CompactionEntry`；恢复（`--continue/--resume/--session`）按当前分支**投影重建**，直接用「摘要 + `firstKeptEntryId` 起」→ 属**持久化断点**路线（`pi-persist-01`、`pi-recover-01`）。
- **错误与副作用**：溢出恢复**只允许一次** compact-and-retry（`_overflowRecoveryAttempted`）；摘要生成遇 `length`/`error` 即失败、**不写检查点**；压缩失败仅保留已发生的 omission 编辑，不产生新检查点；摘要调用走 `retryAssistantCall`（`pi-fail-01/02`）。
- **缓存及总成本**：**摘要请求显式 `cacheRetention:"none"`**（一次性、不复用，避免写缓存）；会话侧有**缓存预热 `CacheWarmer`**（默认 `cacheWarming:"streaming"`）与缓存命中统计 `cache-stats`（`pi-cache-01`）。

## 4. "默认" vs "安装扩展以后"（本任务硬要求 A）

> 扩展点机制：pi 加载 **TypeScript 扩展模块**，其工厂函数可注册工具/命令/快捷键/provider/渲染器/**事件处理器**（`如何 pi works`：`docs/how-pi-works.md` "Extensions and resources"）。**默认分发（未装扩展）不含下列扩展态行为。**

| 维度 | 默认（pi 本体，未装扩展） | 扩展能改什么（装上扩展以后） | 证据 |
|---|---|---|---|
| 摘要内容/格式 | 内置结构化摘要（Goal / Constraints & Preferences / Progress / Key Decisions / Next Steps / Critical Context + 文件清单） | `session_before_compact` 可**取消压缩**，或**提供自定义摘要**（`{compaction:{summary,firstKeptEntryId,tokensBefore,usage,details}}`）；可换模型、自定义 `details` | `pi-summary-01`、`pi-ext-01` |
| 压缩触发 | 内置阈值触发 + `/compact` | 事件可读 `reason(manual/threshold/overflow)`、`willRetry`；可读 `preparation.settings`；**但不能改内置阈值常量**（阈值来自 settings，不是扩展） | `pi-ext-01` |
| 请求消息 | 系统提示词 sections + 投影消息 + 工具声明 | `context` / `context_with_system` 事件**可改写每次 LLM 调用前的消息**；`before_provider_request` 可**替换最终 payload** | `pi-ext-02` |
| 技能/规则/主题 | 内置发现（AGENTS.md、skills、prompt templates、themes） | 扩展可**注册**新的 tool/command/provider/renderer；`/preload`、资源发现事件可增补 skill/prompt 路径 | `pi-rule-02`、`pi-ext-02` |
| 子 Agent | **无**（刻意不含） | 扩展**可以实现**自己的子代理/委派（社区/第三方），但那属**扩展行为**，不得记为 pi 默认 | `pi-cm09-01` |
| 长期记忆 | **无** | 扩展可自行落盘/注入记忆 | `pi-memory-01` |
| 工具集 | 内置 `read/bash/edit/write`（+`grep/find/ls/powershell` 等），可用 `--tools/--no-builtin-tools` 门控 | 扩展可增删工具、可 `hidden`/`reachesTools`（如 `tool_search`、`codemode`） | `pi-ext-02`、`system-prompt.ts:150-160` |
| 会话/分支 | 内置 JSONL 树 + `/tree /fork /clone` + 分支摘要 | `session_before_switch/session_before_fork/session_before_tree` 可取消或自定义摘要；`custom` 条目可持久化扩展状态 | `pi-ext-01`、`pi-persist-01` |

**一句话边界**：pi 的"默认"是**最小内核**（无子代理、无长期记忆、无 plan mode）；"可扩展"体现在**事件钩子 + 资源注册**两层。凡"扩展能做到"的能力（子代理、长期记忆），**默认不含**，报告中必须分列。
