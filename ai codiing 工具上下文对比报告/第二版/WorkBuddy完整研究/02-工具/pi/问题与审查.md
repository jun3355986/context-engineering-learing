## 2. CM-09 不适用说明（本任务硬要求）

**CM-09（子 Agent 交接）对 pi 不适用——pi 刻意不含 sub-agents。**

| 项 | 内容 |
|---|---|
| 定位 | README 原文："Pi ships with powerful defaults but **skips features like sub-agents and plan mode**. Ask Pi to build what you want, or install a package that does it your way." |
| 源码核验 | **主仓**检索无内建子代理生成/独立上下文/交接/分叉协议实现（命中的 `delegate` 均为"把文件/命令操作委托给远端系统（如 SSH）"的**工具执行器扩展点**，与子代理无关）；仓库**随附** `packages/coding-agent/examples/extensions/subagent/` 示例扩展（属**扩展层**、非默认核心），另有实验性独立包 `packages/durable` |
| 与 T02 一致性 | T02 问题地图 §C 已注记"**pi：不适用**——pi 刻意不含 sub-agents"；本包据源码与 README **确认该注记正确** |
| 默认 vs 扩展 | **默认 = 无**；扩展**可以**实现子代理，但那属**扩展行为**，报告与对比中必须与默认分列（见 `工具概览.md §4`） |
| 结论ID | `pi-cm09-01` |

> 说明纪律：**不得**写成"未找到 / 尚未证实"，而应写成"**不适用（刻意不含）**"。

### 6.2 LQ-10 裁决（pi 侧）
**pi = 持久化断点（路线 B）**：压缩产物（summary + firstKeptEntryId）持久化于 JSONL；恢复按当前分支投影重建，不重放全部历史重算；原始条目仍在文件但不再进模型。证据：`session-manager.ts:476-512,1261-1287,1766-1801`；`docs/how-pi-works.md`、`docs/sessions.md`。

### 6.3 T08（oh-my-pi）可比字段清单
1. **整理触发**：阈值表达式 + 默认值 + 触发时机集合 + 手动入口。
2. **保留预算**：keepRecent 默认值 + 切点规则（是否同样避 toolResult）。
3. **工具输出**：行/字节阈值 + 保头/保尾分配 + 是否落盘与路径进上下文方式。
4. **恢复方式**：持久化断点 vs 重放历史；是否删原条目。
5. **扩展点**：钩子集合（是否新增子代理/LSP 等 pi 没有的能力）。
