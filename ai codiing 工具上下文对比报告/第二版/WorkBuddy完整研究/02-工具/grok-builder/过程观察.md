# Grok Build · 过程观察

> **本文件解决什么问题**：给**已运行观察**（1 项，分发件非侵入观察）的命令 / 预期事件 / 判据 / 停止条件 / 退出码，并给**未运行项**的 `NOT_RUN + 确切原因`；登记**本机污染**与**版本双重口径**与**归因限制**。
> **观察纪律（T03 + 全组）**：①退出码为准 + 至少一次负例；②版本双重口径；③本机污染登记；④UNOBSERVABLE ≠ 没有实现；⑤不把"源码阅读/网页 PASS"当实验通过；⑥归因限制必写；单轮 ≤10 分钟、≤20 次工具动作。

## 2. 已运行观察：`OBS-grok-dist-01`（分发件非侵入观察）

> **性质**：**分发件非侵入观察**（读帮助文本、配置文件、目录布局、会话落盘结构、`grok inspect` 发现面）。**未做**任何模型推理调用、**未**读用户会话正文内容、**未**改全局配置、**未**联网发帖。
> **不是**性能对比实验，也**不是**端到端"产品默认行为"验证。

### 2.1 命令 / 预期事件 / 判据 / 停止条件

| 步骤 | 命令 | 预期事件 | 判据（退出码为准） | 停止条件 |
|---|---|---|---|---|
| S1 | `grok --version`（会话起始） | 打印版本 | exit 0 且含 `1.0.50` | 非 0 或版本异常 → 停 |
| S2 | `grok --help` / `grok memory/sessions/usage/export/inspect/agent/trace --help` | 打印帮助 | exit 0 | 非 0 → 停 |
| S3 | `shasum -a 256 ~/.grok/downloads/grok-1.0.50-*` | 哈希 | 与版本表一致 | 不一致 → 停并登记 |
| S4 | `file ~/.grok/bin/grok`、`ls -la ~/.grok/` | 类型/布局 | — | — |
| S5 | `grok inspect --json`（cwd=`/tmp/grok-obs-01`，合成、非 git、未信任） | **20** 键 JSON | **exit 0** | 非 0 → 停 |
| S6（负例） | `grok --definitely-not-a-flag` | 报错 | **exit=2**（实测；验证判据能报错） | — |
| S7 | 直跑冻结件提取 1.0.50 文档 | 生成 `docs/user-guide/*` | exit 0 | 非 0 → 停 |
| S8 | `diff` 两版文档 | 差异行数 | — | — |

### 2.2 运行记录（原始输出摘录）

```text
# S1 会话起始
$ grok --version
grok 1.0.50 (c58f321264ba)        # exit 0

# S3 冻结件哈希（与版本表 §2 逐位一致）
$ shasum -a 256 ~/.grok/downloads/grok-1.0.50-macos-aarch64
af41b1d65d4116ff649a689ad9d070d4c2abe255737d46ba0b3e8161345696e6

# S5 inspect（合成目录）
$ cd /tmp/grok-obs-01 && grok inspect --json > /tmp/grok-inspect-01.json; echo exit=$?
exit=0        # JSON 37,471 bytes；grokVersion=1.0.52；projectTrusted=false；projectRoot=null

# S6 负例
$ grok --definitely-not-a-flag
error: unexpected argument '--definitely-not-a-flag' found   # exit=2

# S7 用冻结件提取 1.0.50 文档（离线）
$ GROK_HOME=/tmp/grok-home-1050 GROK_DISABLE_AUTOUPDATER=1 \
    ~/.grok/downloads/grok-1.0.50-macos-aarch64 version
grok 1.0.50 (c58f321264ba)        # exit 0；提取出 docs/user-guide/01..27

# S8 文档 diff（1.0.50 vs 1.0.52，差异行数）
26-config-reference.md 85 / 17-sessions.md 37 / 14-headless-mode.md 29 /
13-memory.md 24 / 05-configuration.md 18 / 12-project-rules.md 3 / 04-slash-commands.md 47
# 24-monitoring-usage.md：无差异
```

> **S6 判据说明**：负例证明"帮助/参数解析对错误输入**确实报错并以 exit=2 退出**"，即判据不是"退出码恒 0"。`grok <未知词>`（无 `--`）会被当作**初始 prompt 启动 TUI**——本包**不采用**该形态做负例（避免启动交互界面）。

### 2.3 归因限制（规范 §4.6）

1. **本机环境受第三方扩展污染**（见 §3），`grok inspect` 的 hooks/skills/mcpServers 计数**不代表产品默认**，只作**行为样点**。
2. `grok inspect` 运行在 **1.0.52**（②口径），与冻结件 **1.0.50**（①口径）**不一致** → 其结果**不得**用于验证基于 1.0.50 写的结论。
3. S5 的**项目规则未加载**是"非 git + 未信任"的组合结果，**不能**外推为"Grok 不读 AGENTS.md"。
4. 本观察**不含**任何模型推理；所有"摘要/记忆/压缩"机制**未端到端触发**（见 §4）。
5. **环境变更登记**：本包会话期间 `grok` 因 `auto_update`（默认开）**自动从 1.0.50 升级到 1.0.52**——这是**本包引发的环境变更**，已如实登记；冻结件 1.0.50 **未被删除**，可复现。

## 3. 本机污染登记（必填）

| 项 | 实测 | 影响 |
|---|---|---|
| 第三方 hooks | `grok inspect` 报 **7** 条，全部来自 `~/.claude`；`hookLoadErrors` **6** 条 | 本机行为样点不代表默认 |
| 技能 | **61** 条（含 `~/.grok/skills/` 与 claude 兼容） | 技能注入面被放大 |
| MCP | **4** 个 server | 工具集被放大 |
| 兼容单元 | claude + cursor 的 skills/rules/agents/mcps/hooks/sessions **全 `enabled=true`** | 规则/技能来源被放大 |
| 记忆 | `~/.grok/memory-v2/` 脚手架存在，`global/MEMORY.md` = "No memory files have been recorded yet." | 记忆被启用过（或脚手架自动建），内容为空 |
| 配置告警 | `configWarnings`：`privacy` 键未知 | `~/.grok/config.toml` 有非当前版本键 |
| 平台 | macOS（darwin-arm64） | Windows/Linux 未核验 |

**处置**：本包所有"默认行为"结论以**官方文档承诺**为准；本机观测仅作**行为样点**，不得当产品默认。

## 5. 交给 T19 的复现规程模板（供统一实验）

> 目标：把本包的"文档承诺级"结论升级为"干净环境实测"。**须在干净环境（无第三方 hooks/skills/MCP）**复现，并固定版本。

1. **准备**：`GROK_HOME=/tmp/t19-grok`（干净）；`GROK_DISABLE_AUTOUPDATER=1`；记录 `grok --version` 与分发包 sha256；`GROK_SUBAGENTS`/`GROK_MEMORY` 显式设定。
2. **触发线**：合成任务逼近窗口；用 `/context`、`/session-info`、`signals.json` 记录 `contextWindowUsage`；核对是否在 **85%** 触发；用 `[session] auto_compact_threshold_percent = 70` 复现提前触发。
3. **工具输出**：`bash` 产生 >65,536 字节输出；核对截断与是否落盘；构造 >4000 字符旧工具结果，验证软裁（头 1500/尾 1500）与 >10 轮硬清。
4. **连续压缩**：连续触发 3 次压缩；用 `grok_code.compaction{tokens_before,tokens_after}` 与 `compaction_checkpoints/` 记录；检查关键事实是否丢失（**检查器**判据，不靠模型自述）。
5. **恢复**：`grok -p ... -s <uuid>` 建会话 → 压缩 → `/rewind` → 核对**磁盘文件是否还原**（裁决 Q-01）；`grok export`/`grok usage` 取回。
6. **记忆**：`GROK_MEMORY=1` 开；跑若干轮 → `/flush` → 检查 `observations/_inbox/` 计数 → `/dream` → 检查 topics；核对索引注入字节（`grok-shell-memory_injection`）。
7. **判据**：退出码 + 检查器脚本；每条件首轮重复 3 次，记中位数与范围；不声称统计显著。
