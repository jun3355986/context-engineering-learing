# OpenCode v1 · 数据走查

> 每条 `DW-*` 走完"**输入 → 处理顺序 → 前后对照（原样留下/变摘要/移除/落盘）→ 写回 → 找回入口**"。
> **数字纪律**：公式 + 代入值 + 结果，标【源码常量】/【演示】/【测试样本】。**无实测处标 NOT_RUN。**

## DW-assembly-01 · 请求组装（CM-01）

- **输入**：一次任务的 `messages`（投影后）+ agent 定义 + 会话权限。
- **处理顺序**：① `filterCompactedEffect` 投影 → ② `SessionReminders.apply` 注入 plan/build 提醒 → ③ 插件 `experimental.chat.messages.transform` → ④ 并行取 `skills/env/instructions/mcp` 与 `toModelMessagesEffect(msgs)` → ⑤ 拼 `system` 数组 → ⑥ `LLMRequestPrep.prepare` 合成一条 system、插入 messages、过滤/排序工具。
- **前后对照**：

| 对象 | 前 | 后 |
|---|---|---|
| 系统块 | 无 | **一条 system 字符串**（agent.prompt + env + instructions + mcp + skills + user.system，`\n` 连接） |
| 消息 | 磁盘全部消息 | `[system 消息, …投影消息…, (末步)MAX_STEPS_PROMPT]` |
| 工具 | 注册表全量 | 按权限/`user.tools` 过滤后**按名排序** |

- **写回**：请求交给 `llm.stream`；模型事件写回部件，**下次循环重新投影**（非增量）。
- **找回入口**：原始消息在 DB（`MessageV2.page`）；组装结果不落盘（仅日志）。
- **失败分支**：带 `error` 的 assistant（非中止型）**整条跳过**；`pending/running` 工具补 `output-error`（配对不变量）。
- **运行证据**：NOT_RUN（需真实 provider）。

## DW-rule-01 · 项目规则发现（CM-02）

- **输入**：工作目录 `ctx.directory` / 工作树 `ctx.worktree`；`config.instructions`。
- **处理顺序**：① 全局层按 `globalFiles` 顺序取**首个存在** → ② 项目层按 `instructionFiles` 顺序 `findUp` 取**首个命中**（不叠加祖先）→ ③ `config.instructions` 逐项 glob/URL → ④ `read` 时 `resolve` 沿目录向上附就近规则（每消息 `claims` 去重一次）。
- **前后对照**：

| 对象 | 前 | 后 |
|---|---|---|
| 规则文件 | 磁盘文件 | 读入 → `Instructions from: <path>\n<content>` 进 system |
| 就近规则 | 磁盘文件 | 附到 `read` 结果的 `<system-reminder>` 块 |
| URL 规则 | http(s) 文本 | 5s 超时读入；失败→空串（静默） |

- **写回**：system 数组（每次请求重算）。
- **找回入口**：磁盘文件路径；`Instruction.systemPaths()` 可枚举。
- **边界/失败**：全局与项目各**只取首个**（多祖先不叠加）；URL 失败静默（不报错）。
- **运行证据**：NOT_RUN。

## DW-skill-01 · 技能渐进式披露（CM-02）

- **输入**：技能目录（`.claude/skills/**/SKILL.md`、`.agents/...`、`{skill,skills}/**/SKILL.md`、`skills.paths`、`skills.urls`）。
- **处理顺序**：① `discoverSkills` 扫描去重 → ② `loadSkills` 解析 frontmatter（name/description）→ ③ 系统提示词 `Skill.fmt(verbose)` **只列** name/description/location → ④ 需要时模型调用 `skill` 工具读正文。
- **前后对照**：

| 对象 | 前 | 后 |
|---|---|---|
| 技能正文 | 磁盘 `SKILL.md` | **默认不进请求**；`skill` 工具调用后才进 |
| 技能索引 | 无 | system 里 `<available_skills>`（name/description/location） |

- **写回**：system 块（每次请求重算）。
- **找回入口**：`skill` 工具 + 磁盘路径。
- **边界/失败**：frontmatter 缺 `name` → 跳过；重复名 → 告警后后者覆盖；`skills.urls` 远端 `index.json` 拉取失败 → 空。
- **运行证据**：NOT_RUN。

## DW-retrieval-01 · read 分页（CM-03）

- **输入**：文件路径 + `offset`（1 起）+ `limit`。
- **处理顺序**：按行流式读，跳过前 `offset-1` 行，最多收 `limit` 行；逐行按 `MAX_LINE_LENGTH=2000` 字符截断（追加 `... (line truncated to 2000 chars)`）；累计字节超 `MAX_BYTES=51200` 即停并标 `cut`。
- **前后对照**：

| 对象 | 前 | 后 |
|---|---|---|
| 文件全文 | 磁盘 | 只返回窗口内行；超限行/字节截断 |
| 续读 | — | 提示 `Use offset=<next> to continue` |
| 就近规则 | 磁盘 | 附 `<system-reminder>` |

- **写回**：工具结果进消息列表。
- **找回入口**：`read` + `offset`；或 `grep`。
- **边界例子**：单行 >2000 字符 → 截断并加后缀；总量到 `51200` 字节 → 提示 "Output capped at 50 KB"。
- **运行证据**：NOT_RUN。

## DW-trunc-01 · 工具输出限长（CM-04）★含边界

- **输入**：工具原始文本 `text`；`options.direction`（默认 head）。
- **处理顺序**：`Truncate.output`：先比 `lines.length<=2000 且 totalBytes<=51200`（否则截断）；head 分支逐行累加，行数达 2000 **或** 字节超 51200 即停（`hitBytes`）；`removed`/`unit` 随停因切换；原文 `write(text)` 落盘；返回预览 + 标记 + 提示。
- **可算数字**：

| 项 | 公式 | 代入 | 结果 | 角标 |
|---|---|---|---|---|
| 行上限 | `MAX_LINES` | — | **2000 行** | 【源码常量】`truncate.ts:14` |
| 字节上限 | `MAX_BYTES` | `50×1024` | **51200 字节** | 【源码常量】`truncate.ts:15` |
| 保留期 | `RETENTION` | `7 天` | 604800 s | 【源码常量】`truncate.ts:12` |
| 演示：3000 行 ASCII | 到线判据 | 3000>2000 | 截到 2000 行，`unit="lines"` | 【演示】 |
| 演示：单行 60000 字节 | 到线判据 | 60000>51200 | 第 1 行即 `hitBytes`，输出 0 行 | 【演示】 |

- **前后对照**：

| 对象 | 前 | 后 |
|---|---|---|
| 工具输出 | 全文 | 预览（head/tail）+ `...N lines/bytes truncated...` + 提示 |
| 原文 | 内存 | **落盘**到截断目录（文件名 `tool_*`），保留 7 天 |

- **写回**：`content`（预览）进消息列表；`outputPath` 供取回。
- **找回入口**：落盘路径（提示里给）；`Grep`/`Read offset/limit`（若 agent 有 `task` 权限则建议委派 explore）。
- **边界/失败**：混合 CJK 时按**整行**累加字节（不切半字）；`write` 失败 `orDie`；清理目录不可读静默。
- **运行证据**：NOT_RUN（产品端到端）。

## DW-trunc-02 · 压缩序列化限长（CM-04）

- **输入**：被选中压缩的消息（`selected.head`）。
- **处理顺序**：`serialize` 把消息转文本；工具结果：已 `compacted`→`[Old tool result content cleared]`，否则 `truncate(output)`（**2000 字符**上限 + `\n[truncated]`）。
- **可算数字**：`TOOL_OUTPUT_MAX_CHARS=2000`【源码常量】`compaction.ts:30`；**单位是"字符"**，非字节/token。
- **前后对照**：原文 → 摘要提示词里的 `[Tool result]: …`（≤2000 字符）；`compacted` → 占位串。
- **写回**：进摘要提示词（不落盘）。
- **找回入口**：无（摘要提示词是瞬时输入）。
- **边界**：CJK 下 2000 字符 ≠ 2000 字节（1 个 CJK 字符 = 3 UTF-8 字节）。
- **运行证据**：NOT_RUN。

## DW-trigger-01 · 有效窗口与溢出（CM-05）★含算例

- **输入**：`model.limit.context`、`model.limit.input`、`maxOutputTokens`、`cfg.compaction.reserved`、上一轮 `tokens`。
- **处理顺序**：`usable` 先算 `reserved`，再按有无 `limit.input` 二选一；`isOverflow` 取 `count`（`total` 或四项和）与 `usable` 比较。
- **可算数字**：

| 项 | 公式 | 代入（演示） | 结果 | 角标 |
|---|---|---|---|---|
| 预留 | `min(COMPACTION_BUFFER, maxOutputTokens)` | `min(20000, 32000)` | **20000** | 【源码常量】`overflow.ts:8,16` |
| 有效窗口（有 input 上限） | `limit.input − reserved` | `200000 − 20000` | **180000** | 【演示】 |
| 有效窗口（无 input 上限） | `context − maxOutputTokens` | `200000 − 32000` | **168000** | 【演示】 |
| 到线 | `count ≥ usable` | `count=180000, usable=180000` | **true** | 【演示】 |
| 关闭自动 | `auto===false` | — | 恒 false | 【源码常量】`overflow.ts:28` |

- **前后对照**：纯判定，**无状态写回**。
- **写回**：`isOverflow` 结果驱动 `compaction.create`（CM-06）。
- **找回入口**：不适用。
- **边界**：`context===0` → `usable=0` 且 `isOverflow=false`（未知窗口不触发）。
- **运行证据**：NOT_RUN。

## DW-compact-01 · 压缩流程（CM-06/CM-07）

- **输入**：`messages`、`parentID`（压缩用户消息）、`auto`、`overflow`。
- **处理顺序**：① 找 parent（须 user，否则抛错）→ ② 若 `overflow` 尝试 `replay` 最近非压缩 user 消息并裁剪 messages → ③ `completedCompactions` 剔除历史压缩对，取 `previousSummary` → ④ `select` 选尾（见 DW-summary-02）→ ⑤ 插件 `compacting`（可替换 prompt）→ ⑥ `buildPrompt` 生成摘要提示词 → ⑦ 建 `summary:true` assistant 消息 → ⑧ `processor.process` 调模型生成摘要 → ⑨ `auto && result==="continue"` 时追加合成 continue（或 replay 原消息）→ ⑩ 更新 `compactionPart.tail_start_id`。
- **前后对照**：

| 对象 | 前 | 后 |
|---|---|---|
| 历史 | 全部消息进请求 | 旧消息**移出请求**（磁盘保留） |
| 新增 | — | 1 条 `type:"compaction"` user 消息 + 1 条 `summary:true` assistant 消息 |
| 保留段 | — | `tail_start_id` 起原样留下 |

- **写回**：`session.updateMessage/updatePart`（事件→DB）。
- **找回入口**：`filterCompacted` 重建；原始消息仍在 DB。
- **失败分支**：`result==="compact"`（摘要请求本身超限）→ 写 `ContextOverflowError`、`finish:"error"`、`return "stop"`。
- **运行证据**：NOT_RUN。

## DW-summary-01 · 摘要提示词（CM-07）

- **输入**：`previousSummary?`、`context[]`（序列化对话）。
- **处理顺序**：`buildPrompt` 无旧摘要 → `conversation + 新建指令 + TEMPLATE`；有旧摘要 → `conversation + <prior-summary> + UPDATE_INSTRUCTIONS + TEMPLATE`。
- **前后对照**：旧摘要文本 → 被嵌入提示词 → 模型产出**新摘要**（旧摘要**丢弃**）。
- **写回**：新摘要作为 `summary:true` assistant 消息正文。
- **找回入口**：`summaryText()` 从该消息文本部件取；历史摘要对由 `completedCompactions` 枚举。
- **边界**：增量合并**有损**（"未带过来即丢失"）。
- **运行证据**：NOT_RUN（需真实模型）。

## DW-summary-02 · 保留预算与选尾（CM-07）★含算例

- **输入**：`messages`、`cfg.compaction.preserve_recent_tokens`、`cfg.compaction.tail_turns`、`usable`。
- **处理顺序**：`preserveRecentBudget` 定预算；`turns` 以 user 消息切 turn；`select` 从最新 turn 往回累加，装不下用 `splitTurn` 找 turn 内切点。
- **可算数字**：

| 项 | 公式 | 代入（演示） | 结果 | 角标 |
|---|---|---|---|---|
| 预算（未配置） | `min(15000, max(2000, floor(usable×0.25)))` | `usable=180000` | `min(15000, max(2000, 45000))` = **15000** | 【演示】 |
| 预算（小窗口） | 同上 | `usable=8000` | `min(15000, max(2000, 2000))` = **2000** | 【演示】 |
| 常量 | `MIN/MAX_PRESERVE_RECENT_TOKENS` | — | **2000 / 15000** | 【源码常量】`compaction.ts:32-33` |

- **前后对照**：尾部 turn → **原样保留**（进 tail）；更早 → 进摘要输入。
- **写回**：`tail_start_id` 写入 compaction 部件。
- **找回入口**：`filterCompacted` 按 `tail_start_id` 取回保留段。
- **边界**：`tail_turns<=0` → 不保留任何尾（head=全部）；整 turn 装不下 → 切点落在 turn 内 message 边界；无合适切点 → 记 `tail fallback` 日志。
- **运行证据**：NOT_RUN。

## DW-summary-03 · prune 擦旧工具输出（CM-07）★含边界

- **输入**：会话消息；`cfg.compaction.prune`。
- **处理顺序**：默认**关**（直接 return）；开启后从最新往回，跳过 `skill` 工具与 `compacted` 部件，`total` 超 `PRUNE_PROTECT=40000` 后累计 `pruned`；若 `pruned > PRUNE_MINIMUM=20000` 才真正给 `toPrune` 打 `time.compacted`。
- **可算数字**：保护 **40000 token**【源码常量】`compaction.ts:29`；最小节省 **20000 token**【源码常量】`compaction.ts:28`；`turns<2` 不处理。
- **前后对照**：

| 对象 | 前 | 后 |
|---|---|---|
| 最近 40000 token 工具输出 | 在请求 | **原样**（受保护） |
| 更旧工具输出（可擦>20000） | 在请求 | **打 `time.compacted`**（不再进请求，**原文仍在库**） |

- **写回**：`part.state.time.compacted = Date.now()` → `session.updatePart`。
- **找回入口**：DB 原文仍在；`serialize` 显示 `[Old tool result content cleared]`。
- **边界**：可擦量 **≤20000** → **不擦**（避免低收益）；遇摘要消息 `break`；`skill` 工具输出**永不擦**。
- **运行证据**：NOT_RUN。

## DW-fail-01 · 重试退避（CM-11）★含算例

- **输入**：provider 错误 + attempt。
- **处理顺序**：`retryable` 判是否重试（溢出/不可重试直接停）→ `policy` 在 `attempt > RETRY_MAX_RETRIES` 停 → `delay` 算等待（头优先，否则指数 + 抖动）。
- **可算数字**：

| 项 | 公式 | 代入 | 结果 | 角标 |
|---|---|---|---|---|
| 退避 | `2000×2^(n-1)×(1+0.25·rand)` | `n=1, rand=0` | **2000 ms** | 【源码常量+演示】`retry.ts:26-28,80-83` |
| 退避 | 同上 | `n=3, rand=0` | **8000 ms** | 【演示】 |
| 无头上限 | `min(exponential, 30000)` | `n=6, rand=0` | **30000 ms**（被夹） | 【源码常量】`retry.ts:29,77` |
