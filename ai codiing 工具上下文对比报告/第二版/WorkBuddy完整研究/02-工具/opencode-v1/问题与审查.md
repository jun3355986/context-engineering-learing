## 3. 旧结论 / 冲突裁决（逐条）

| ID | 旧表述 | OpenCode v1 侧裁决 | 依据 |
|---|---|---|---|
| **C-01/C-02** | 触发阈值"90%–95%"总括 | **限制**：v1 用**绝对预留**口径（`reserved=min(20000,maxOutputTokens)`），**非百分比** | `ocv1-trigger-01/02` |
| **C-03** | "压缩不可逆 / 不进入恢复上下文" vs "历史物理保留" | **支持"两事实并存"**：压缩后旧消息**磁盘保留**（DB），模型可见层用替代历史（压缩条目+摘要+保留段） | `ocv1-summary-04`、`ocv1-persist-01` |
| **C-04 / LQ-09** | "旧摘要只做字符串级 merge"（无损暗示） | **判为有损**：增量合并明说"未带过来即丢失、冲突以新对话为准"；具体失真**未决（待 T19 连续压缩）** | `ocv1-summary-01`、DW-summary-01 |
| **C-05** | 桩函数被当作已实现能力 | v1 侧**未发现**把桩当默认；`prune` 明确默认 `false`（条件态已分列） | `ocv1-summary-03` |
| **C-06** | `len(text)//4` 对中文"保守" | **支持"字符/4"口径**：`estimate = round(length/4)`（字符，非字节）；CJK 下**偏低估**（4 字符=12 字节只算 1）——由 `OBS-ocv1-token-01` 实测佐证；对触发的**净影响未裁决**（需 T19） | `OBS-ocv1-token-01`、`ocv1-trigger-02` |
| **C-10** | 多层管道说法（Claude 六层） | v1 **不适用**；**层数不是维度**——v1 是"单道裁剪 + 压缩 + 重建"，非层叠管道 | `ocv1-trunc-01`、`ocv1-summary-04` |
| **C-12 / LQ-10** | "resume 绝不可能找回"；resume 两条路线 | **裁决 = 持久化断点路线（B）**；**限制**"绝不可能找回"为"默认、模型可见层"——原始消息在 DB 可读 | `ocv1-recover-01`、`ocv1-persist-01` |
| **LQ-04** | L1 是否保留源文？工具输出原文存哪？ | **保留**：消息/部件落 DB；工具输出超限**落盘**到截断目录（7 天） | `ocv1-persist-01`、`ocv1-trunc-01` |
| **LQ-05** | 三家具体压缩阈值全表逐项复核 | v1 侧给出：`usable = limit.input − reserved`（`reserved=min(20000,maxOutputTokens)`）；**v1 非 pi/omp 的百分比/固定预留口径** | `ocv1-trigger-01` |
| **LQ-11** | 硬上限（阻塞线）/ 为什么不到 100% | v1 **单一整段线** `usable`（扣 `reserved`），**无** Codex 式"先扣有效窗口再扣缓冲"两笔钱结构 | `ocv1-trigger-01` |
| **T02 §G** | OpenCode v1/v2 同仓库两条 tag 线 | **支持**（澄清）：快照内 `@opencode/v2/*` 服务标签与 v1 出货路径并存，须分列 | `ocv1-version-02` |
| 版本表 Q1/Q2 | v1=`v1.19.0`、v2=`v2.0.29` beta | **支持**（身份口径）；本包只做 v1 | `ocv1-version-01` |

### 7.1 结论表候选（并入 `00-管理/结论表.md`）
- `ocv1-*` 共 **25** 张（族见证据卡计数）。**高风险待复核**：`ocv1-trigger-01`（`usable`/`reserved` 公式）、`ocv1-trunc-01`（2000 行/51200 字节/7 天）、`ocv1-summary-02`（保留预算公式）、`ocv1-summary-03`（prune 40000/20000 默认关）、`ocv1-compact-01`（自动压缩两入口）、`ocv1-recover-01`（持久化断点）、`ocv1-cache-01`（缓存标记）、`ocv1-memory-01`（未发现默认实现）。

### 7.2 冲突回执（并入 `00-管理/冲突表.md`）
- **C-03 / C-12 / LQ-10**：v1 侧 = **持久化断点**；"绝不可能找回"**限制为默认模型可见层**。
- **LQ-05 / LQ-11 / C-01 / C-02**：v1 用**绝对预留** `min(20000,maxOutputTokens)`，**非百分比、非两线结构**。
- **C-04 / LQ-09**：**未决**，依赖 T19。
- **C-06**：v1 走"字符/4"，CJK **偏低估**（`OBS-ocv1-token-01`）；净影响未裁决。
- **C-10**：v1 非层叠管道；支持"层数不是维度"。
- **C-05**：`prune` 默认关，条件态已分列。

### 7.3 术语增补候选（并入 `00-管理/术语表.md`，主 Agent 合并）
- **替代历史重建（`filterCompacted`）**：OpenCode v1 把"压缩条目+摘要+保留段+后续"重排为模型可见历史的投影函数。
- **保留尾起点（`tail_start_id`）**：压缩后原样保留段的起始消息 id（恢复/重建用）。
- **截断目录（truncation dir）**：工具输出超限原文的落盘位置（文件名 `tool_*`，保留 7 天）。
- **保留预算（`preserve_recent_tokens`）**：压缩后保留最近 turn 的 token 预算（默认 `usable×0.25` 夹 `[2000,15000]`）。
- **压缩前裁剪（`prune`）**：擦除旧工具输出的条件机制（默认关；保护 40000/最小节省 20000；`skill` 工具受保护）。
- **doom loop**：连续 3 次相同工具+相同输入触发的防循环询问。

### 7.4 T10 可复用经验（交 T10 与主 Agent）
1. **monorepo 同名陷阱**：同一快照内 v1 出货路径与 `@opencode/v2/*` 在建路径**并存**——**先按服务标签/引用关系定版本归属**，再引用行号；v1 侧的**死导入**（`session.ts:13-14`）**不是**使用证据。
2. **共享模块**：v1 的摘要提示词模板定义在 `packages/core/src/session/compaction.ts`（v1 经 `import { buildPrompt }` 使用）——引用时**标注定义位置**，避免"跨版本误引"。
3. **观察三行**：入口自报 / 快照 SHA / 是否一致；本机 opencode 已安装但**受第三方插件污染**——产品默认结论留 T19 干净环境。
4. **函数级真实执行**：对**无 import 的纯函数**（如 `Token.estimate`）可 `bun` 直接跑快照文件；检查器必带**负例**，退出码为准。
