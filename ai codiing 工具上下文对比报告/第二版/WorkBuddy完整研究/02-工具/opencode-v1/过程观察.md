## 1. 观察 `OBS-ocv1-token-01` · 本地 token 估算函数级执行（已运行）

**目的**：验证 `ocv1-trigger-02`/`ocv1-summary-02` 依赖的**本地近似估算**口径——"**字符数 / 4**（非字节/4）"——在**出货代码**上成立。

**为什么是"函数级"而非"产品级"**：v1 出货代码 `packages/opencode/src/util/token.ts` 只是再导出 `@opencode-ai/core/util/token`；后者（`packages/core/src/util/token.ts`）**无任何 import**，可独立执行。这是**真实执行**（非源码阅读），但**不等于**产品端到端验证。

**命令**（工作目录 = 本包 `过程观察/`；快照只读）：
```bash
bun run obs-token-estimate.ts
```

**检查器**（`obs-token-estimate.ts`，合成数据）：3 正向断言 + 1 负例——
1. `estimate("a"×100) === 25`（ASCII 100 字符 → 25）；
2. `estimate("你好世界") === 1`（4 字符 → 1；**若按字节 12/4=3 则判据失败**，用于区分字符/字节口径）；
3. `estimate("") === 0`；
4. **负例**：`estimate("ab") === 0` **应判失败**（实际 `Math.round(0.5)=1`）——证明判据非恒真。

**预期事件 / 判据**：全部断言 PASS 且退出码 0。**停止条件**：任一断言 FAIL 或异常 → 记失败并停止。

**实际结果**（原始输出）：
```text
PASS  estimate(100 个 ASCII 字符) === 25
PASS  estimate('你好世界') === 1（按字符数 4/4，而非字节 12/4=3）
PASS  estimate('') === 0
PASS  负例按预期失败: estimate('ab') === 0（实际为 1，此判据应失败）（实测 false）
{"fn":"estimate","source":"packages/core/src/util/token.ts:3-5","charsPerToken":4,"ascii100":25,"cjk4":1,"cjk4_bytes":12,"empty":0,"ab":1}
EXIT_CODE=0
```

**版本双重口径**：
| 口径 | 值 |
|---|---|
| 实际执行版本（入口自报） | 本机 `opencode --version` = **`1.19.0`**（`exit 0`）；本次**函数级**执行用的是 **bun 1.3.9** 直接跑快照 `.ts` |
| 研究快照 SHA / 冻结分发包 | 快照 **`733b2c6`**（tag `v1.19.0`） |
| 是否一致 | 版本号一致（都 1.19.0）；本次观察**直接读快照文件**，故与快照**同一份代码**；但**未**经产品入口跑该函数 |

**归因限制**：本观察**不涉及模型**，故无"变化来自模型而非机制"的风险；但也**不证明**产品默认参数（各工具调用时传入的字符串）如何影响真实用量估算；**不能**外推到 `usable`/`isOverflow` 的端到端触发。

**污染登记**：见 §3（本次函数级执行**不加载**任何 opencode 插件/配置，纯 `bun` 跑单文件，故不受 §3 污染影响）。

**退出码判据**：`EXIT_CODE=0` = 通过；`EXIT_CODE=1` = 有断言失败。

## 2. 产品入口 `opencode` 端到端观察 · NOT_RUN

**命令（拟）**：`opencode run --model <M> --provider <P> <合成任务>`（随后按 T03 合成任务跑"到线/压缩/恢复"最小观察）。

**NOT_RUN 确切原因**（三要素齐）：
1. **查的路径**：本机 `/Users/junjielong/.opencode/bin/opencode` **存在**，`opencode --version`=`1.19.0`（`exit 0`）——入口**可用**；但端到端机制观察需**真实模型/凭据 + 交互会话**。
2. **凭什么**：真实机制实验的**统一调度在 T19**（任务书 §5 T19；T03 §0）；且本机 `~/.config/opencode/opencode.json` 装有**第三方插件**（§3），受污染环境观测**只能作行为样点、不得当产品默认**（T03 §9）。本任务卡未授权跑真实模型会话。
3. **官方怎么说**：官方入口 `curl -fsSL https://opencode.ai/install | bash`（版本表 §1）；版本表 §3 记本地 `opencode 1.19.0 = v1 最新 tag`。

**结论**：`NOT_RUN`——**不代表** v1 机制不存在；所有机制结论均以**快照源码**为证据，并逐卡标"不能证明"。

**为什么不用快照直接跑产品**：快照无 `node_modules`；在快照内 `bun install` 会**写入只读快照**（违反硬约束），且端到端需模型凭据。故只做**仓库外**的**函数级**观察（§1）。
