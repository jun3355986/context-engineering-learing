## DW-assembly-01 · 请求组装（CM-01）

- **输入**：一次任务的 `loaded.messages`（投影后）+ `loaded.initial`（指令基线）+ agent 定义 + 工具快照。
- **处理顺序**：① `context.select` 合成指令源（`CodeModeInstructions→mcp→references→skills→discovery→builtins→entries`）→ ② `context.load` 投影历史 + 取 `InstructionState.initial` → ③ `runStep` 判步数上限 → ④ `baseTranscript` 生成 `system=[agent.system ?? 基础提示词, initial]` 与 `messages=toLLMMessages(...)` → ⑤ `context.request.primary` 走 `session.context`/`model.request` 钩子、拼请求头/缓存键。
- **前后对照**：

| 对象 | 前 | 后 |
|---|---|---|
| 系统段 | 各指令源原始值 | **2 条 `SystemPart`**：`[agent.system 或 基础提示词, initial]` |
| 指令 | 磁盘 `AGENTS.md`/技能/MCP… | 折叠进 `initial` 基线（+ 后续 `InstructionsUpdated` 增量） |
| 消息 | 磁盘全部消息 | `toLLMMessages(投影消息)`（末步追加 `MAX_STEPS_PROMPT` assistant + `toolChoice:"none"`） |

- **写回**：请求交给 `llm.stream`；模型事件写回部件，**下次循环重新投影**（非增量）。
- **找回入口**：原始消息在 DB（`SessionStore.messages`）；组装结果不落盘（仅日志）。
- **失败分支**：无 agent → `AgentNotFoundError`；location 不匹配 → `interrupt`；指令源 unavailable → `InitializationBlocked`（输入保持 pending）。
- **运行证据**：NOT_RUN（需真实 provider）。

## DW-rule-01 · 指令基线 / 增量 / 就近规则（CM-02）

- **输入**：指令源列表；`InstructionStateTable` 的 `initial_values`/`current_values`；`read` 成功后的目录向上发现结果。
- **处理顺序**：① `InstructionState.observe` 读当前源 vs 存储值 → ② `Instructions.diff` 出 `delta`/`blobs` → ③ `commit` 发 `InstructionsUpdated`（含冻结文本）→ ④ `initial` 渲染纪元基线；⑤ `read` 时向上发现 `AGENTS.md` → `SessionInstructions.load`（claim + `previouslyInjected` 去重）→ 发 `Synthetic`。
- **前后对照**：

| 对象 | 前 | 后 |
|---|---|---|
| 指令基线 | 无 | `initial`（每请求开头，`<available_skills>` 等） |
| 指令变化 | 磁盘变更 | `InstructionsUpdated` 增量（增删改；改出 diff 补丁或整段替换） |
| 就近规则 | 磁盘文件 | `Synthetic` 消息（`Instructions from: <path>\n<content>`），台账去重 |

- **写回**：`InstructionStateTable`（`initial_values`/`current_values`/`epoch_start`/`through_seq`）；`Synthetic` 消息进历史。
- **找回入口**：磁盘文件；`previouslyInjected` 扫 synthetic 元数据台账。
- **边界/失败**：`AGENTS.md` 向上发现**到 Location root 不含**（`instructions.ts:93-98`）；发现失败 `catch→void`（不影响 read）；synthetic 掉出可见历史会**重注入**。
- **运行证据**：NOT_RUN。

## DW-retrieval-01 · read 分页（CM-03）

- **输入**：文件路径 + `offset`（1 起）+ `limit`。
- **处理顺序**：按行读，跳过前 `offset-1` 行，最多收 `limit` 行（**上限 2000**）；逐行按 `MAX_LINE_LENGTH=2000` 字符截断（追加 `... (line truncated to 2000 chars)`）；累计字节超 `MAX_READ_BYTES=51200` 即停并给 `next`。
- **前后对照**：

| 对象 | 前 | 后 |
|---|---|---|
| 文件全文 | 磁盘 | 只返回窗口内行；超限行/字节截断 |
| 续读 | — | 提示 `[Output truncated. Continue reading with offset: <next>]` |
| 媒体 | image/pdf | base64 直读；>20 MiB 拒读 |

- **写回**：工具结果进消息列表。
- **找回入口**：`read` + `offset`；或 `grep`。
- **边界例子**：单行 >2000 字符 → 截断并加后缀；`offset` 越界 → `OffsetOutOfRangeError`；目录读取分页（`list-page`）。
- **运行证据**：NOT_RUN。

## DW-recover-01 · 恢复与 fork（CM-10）

- **输入**：`--continue` / `--session <id>` / `--fork`。
- **处理顺序**：载入会话 → `SessionContext.load` → `SessionHistory.entriesForRunner`（boundary = provenance ?? "local"，从最近完成压缩起读）→（fork）`Session.fork` 按 boundary 复制 + 继承指令基线。
- **前后对照**：

| 对象 | 前 | 后 |
|---|---|---|
| 恢复 | 磁盘存档 | 模型可见 = 压缩条目 + 其后消息（**不重放全部重算**） |
| fork | 原会话 | 新会话（新 id，boundary before/through，指令基线继承） |

- **写回**：fork 写新会话（`SessionEvent.Forked`）。
- **找回入口**：原始消息在 DB；`--session <id>` 指名恢复。
- **边界**：无存档 → 新会话；`--fork` 需配 `--continue`/`--session`（否则 fail）。
- **运行证据**：NOT_RUN。

## DW-fail-01 · 重试退避（CM-11）★含算例

- **输入**：provider 错误 + attempt。
- **处理顺序**：`policy`：`Schedule.min(exponential 2s, spaced 10s)` + `max(recurs 10)` + jitter + `max(delay, retryAfter)`；`session.retry` 钩子可改。
- **可算数字**：

| 项 | 公式 | 代入 | 结果 | 角标 |
|---|---|---|---|---|
| 退避（间隔上限） | `min(2×2^(n-1), 10000)` | `n=1` | **2000 ms** | 【源码常量】`retry.ts:46` |
| 退避 | 同上 | `n=4` | **10000 ms**（被夹） | 【演示】 |
| 上限次数 | `recurs(10)` | — | **10 次** | 【源码常量】`retry.ts:47` |
| 头时限 | `RETRY_AFTER_MAX` | `15 分钟` | 900000 ms | 【源码常量】`retry.ts:32` |
| 超时类上限 | `MAX_TIMEOUT_RETRIES` | — | **3** | 【源码常量】`retry.ts:60` |

- **前后对照**：纯等待与状态（`RetryScheduled`），不改消息。
- **写回**：状态事件。
- **找回入口**：不适用。
- **边界/失败**：`retry-after` 头取 `max(退避, 头值)`；超时类额外限 3 次。
- **运行证据**：NOT_RUN。

## DW-fail-02 · 输出超限 / 中断（CM-11）

- **输入**：`finish==="length"` / 不完整流 / 工具中断/拒绝。
- **处理顺序**：`OutputLimit` → 查最近 3 条（user/assistant），连续 3 条 assistant `length` → `output-limit` 失败；否则合成 `CONTINUE_AFTER_OUTPUT_LIMIT` 续跑。`Continue` → 合成 `CONTINUE_AFTER_INCOMPLETE_STREAM`。工具中断/拒绝 → 未结算工具标 `aborted`、assistant 标 `Step interrupted`。
