## 1. 观察 `OBS-ocv2-token-01` · 本地 token 估算函数级执行（已运行）

**目的**：验证 `ocv2-trigger-02`/`ocv2-summary-02` 依赖的**本地近似估算**口径——"**字符数 / 4**（非字节/4）"，且含 `Math.max(0, …)` 下界——在 **v2 出货代码**上成立。

**为什么是"函数级"而非"产品级"**：v2 出货代码 `packages/core/src/util/token.ts` **无任何 import**，可独立执行。这是**真实执行**（非源码阅读），但**不等于**产品端到端验证。

**命令**（工作目录 = 本包 `过程观察/`；快照只读）：
```bash
bun run obs-token-estimate.ts
```

**检查器**（`obs-token-estimate.ts`，合成数据）：3 正向断言 + 1 负例——
1. `estimate("a"×100) === 25`（ASCII 100 字符 → 25）；
2. `estimate("你好世界") === 1`（4 字符 → 1；**若按字节 12/4=3 则判据失败**，用于区分字符/字节口径）；
3. `estimate("") === 0`（下界）；
4. **负例**：`estimate("ab") === 0` 应为 **false**（实际 `Math.round(0.5)=1`）——证明判据非恒真。

**预期事件 / 判据**：全部断言 PASS 且退出码 0。**停止条件**：任一断言 FAIL 或异常 → 记失败并停止。

**实际结果**（原始输出）：
```text
PASS  estimate('a'×100) === 25
PASS  estimate('你好世界') === 1（按字符 4/4，而非字节 12/4=3）
PASS  estimate('') === 0（下界 Math.max(0, …)）
PASS  负例按预期失败: estimate('ab') === 0 为 false（实际为 1，证明判据非恒真）
{"fn":"estimate","source":"packages/core/src/util/token.ts:5","charsPerToken":4,"ascii100":25,"cjk4":1,"cjk4_bytes":12,"empty":0,"ab":1}
EXIT_CODE=0
```

**版本双重口径**：
| 口径 | 值 |
|---|---|
| 实际执行版本（入口自报） | **v2 产品入口不可用**——本机 `/Users/junjielong/.opencode/bin/opencode --version` = **`1.19.0`（= v1）**（`exit 0`）；本次**函数级**执行用的是 **bun 1.3.9** 直接跑**快照 v2** 的 `.ts` |
| 研究快照 SHA / 冻结分发包 | 快照 **`042d083`**（tag `v2.0.29`，beta） |
| 是否一致 | **不一致**——本机可执行是 **v1（1.19.0）**，**非 v2**；本次观察**直接读快照 v2 文件**，故与快照**同一份代码**；但**未**经 v2 产品入口跑该函数。**归因限制**：本机 opencode 观测**不得**用于验证 v2 结论 |

**归因限制**：本观察**不涉及模型**，故无"变化来自模型而非机制"的风险；但也**不证明** v2 产品默认参数（各工具调用时传入的字符串）如何影响真实用量估算；**不能**外推到 `ceiling`/`due` 的端到端触发。

**污染登记**：见 §3（本次函数级执行**不加载**任何 opencode 插件/配置，纯 `bun` 跑快照单文件，故不受 §3 污染影响）。

**退出码判据**：`EXIT_CODE=0` = 通过；`EXIT_CODE=1` = 有断言失败。

## 2. 产品入口端到端观察 · NOT_RUN

**命令（拟）**：`opencode run --model <M> --provider <P> <合成任务>`（随后按 T03 合成任务跑"到线/压缩/恢复"最小观察）。

**NOT_RUN 确切原因**（三要素齐）：
1. **查的路径**：本机 `/Users/junjielong/.opencode/bin/opencode` **存在**，但 `opencode --version` = **`1.19.0`**——这是 **v1**（版本表 §3 记"= v1 最新 tag v1.19.0"）；**未安装 v2 可执行入口**（v2 官方入口 `npm i -g @opencode/cli`，版本表 §1 第 6 行）。
2. **凭什么**：即便装 v2，端到端机制观察仍需**真实模型/凭据 + 交互会话**，且本机 `~/.config/opencode/` 被**第三方插件/MCP 重度污染**（§3）；受污染环境观测**只能作行为样点、不得当产品默认**（T03 §9）。本任务卡未授权装 v2、也未授权跑真实模型会话。
3. **官方怎么说**：官方入口 `npm i -g @opencode/cli`（版本表 §1 第 6 行）；版本表 §3 记本地 `opencode 1.19.0`（v1），**无 v2 本地行**。

**结论**：`NOT_RUN`——**不代表** v2 机制不存在；所有机制结论均以**快照 v2 源码**为证据，并逐卡标"不能证明"。

**为什么不用快照直接跑产品**：快照无 `node_modules`；在快照内 `bun install` 会**写入只读快照**（违反硬约束），且端到端需模型凭据。故只做**仓库外**的**函数级**观察（§1）。
