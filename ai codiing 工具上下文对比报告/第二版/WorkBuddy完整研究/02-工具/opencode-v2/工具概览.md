## 3. 能力覆盖（一句话版；逐项判定见 `问题与审查.md` §1 十二机制表）

- **请求组装与角色**：`system = [agent.system ?? 基础提示词, 指令基线(initial)]`（**仅 2 段**）；`messages = toLLMMessages(投影消息)`；模型专属系统提示词经插件钩子（gpt/claude/kimi/trinity/muse）；末步追加 `MAX_STEPS_PROMPT` assistant 消息 + `toolChoice:"none"`（`ocv2-assembly-01/02`）。
- **项目规则 / 技能**：规则/技能/MCP/参考资料/内置指令统一为**有序指令源**，按"最共享→最不共享"合成；指令走**纪元基线 + 增量**（`InstructionsUpdated`）；`AGENTS.md` 就近规则以 synthetic 注入 + 台账去重（可重注入）；技能渐进式披露（`<available_skills>`）（`ocv2-rule-01/02`、`ocv2-skill-01`）。
- **资料选择与代码检索**：`read` 分页（默认/上限 2000 行、单行 2000 字符、50 KiB；媒体 >20 MiB 拒读）（`ocv2-retrieval-01`）。
- **单条工具输出治理**：`ToolOutput.truncate`——**2000 行 / 51200 字节先到者、仅 head**；超限原文落盘 `tool-output/tool_<hex>`（**保留 7 天**）；压缩序列化再按 **1250 字符**限长（码点安全）（`ocv2-trunc-01/02`）。

> 【T19 实测更正（2026-10-15）】产品 shell 路径实测为**纯 tail**（与 v1 同向）；「仅 head（无 tail）」**不成立于 shell 路径**；落盘实为 `shell/<hash>/sh_<id>.out`。原函数级观察（`tool-output.ts` 头向通用通道）保留——head 仅在 read 分页与通用默认（证据：`05-实验/T19/记录/08-ocv2.md` §五/§2.7；`T19-结果总表.md` §5 #14）。
- **窗口计量与触发**：`ceiling = window − max(10%W, 16000)`（`buffer` 可覆盖；窗口未知→+∞）；`due` 要求"本 provider 已测量锚点晚于最后 checkpoint"且 `estimateContext ≥ ceiling`（`ocv2-trigger-01/02`）。
- **自动 / 手动压缩**：自动——`runStep` 每步开头 `compact({reason:"auto"})`；溢出——独立 `reason:"overflow"` + 收缩步进 `[0.7,0.5,0.35]`；手动——`/compact` inbox 项在步边界消费；**原生（provider）压缩**——模型元数据 `compaction.type==="native"` 时用加密窗口（`ocv2-compact-01..04`）。
- **摘要 / 裁剪 / 重建**：模板 `Objective/Requirements/Decisions/Work State/Next Move/Relevant Files/Important Context` + "新历史优先"增量 + **模板校验与一次 NUDGE**；保留预算 `keep`（**默认固定 15000**）；请求过大时**文本化 + 丢最旧 exchange**（`[N older exchanges omitted]`）；**未见 `prune`**（配置层标 unsupported）；重建由 `SessionHistory` 按 seq 边界取"最近完成压缩起"（`ocv2-summary-01..04`）。
- **长期记忆**：**未发现默认实现（推断）**——`environment/memory.ts` 是内存 FS 驱动，非记忆（`ocv2-memory-01`）。
- **子 Agent 交接**：**支持**——`subagent` 工具建独立子会话（fresh context），`experimental.subagent_depth` 默认 **1**；前台/后台默认可用（`ocv2-cm09-01`）。
- **保存 / fork / 恢复**：SQLite（drizzle）+ 事件溯源；恢复按 boundary 从最近完成压缩起读（**持久化断点路线**）；`--continue`/`--session`/`--fork`；fork 按 boundary + 继承指令基线；**崩溃 write-ahead claim**（`time_suspended`）+ 遗留压缩/工具结算（`ocv2-persist-01`、`ocv2-recover-01/02`）。
- **错误与副作用**：重试**最多 10 次**、间隔上限 10s、头时限 15 分钟、超时类额外 3 次；输出超限**最多 2 次续跑**；不完整流续跑；工具中断标 `aborted`；**出货路径未发现 `doom_loop` 阈值判定逻辑（推断）**（`doom_loop` 权限动作名仍在 v1 迁移子集，全仓 169 命中）（`ocv2-fail-01/02`）。
- **缓存及总成本**：CLI 侧可证——默认 `"auto"` 在**最后工具 + 首/末 system + 尾 1 条消息**打断点（**上限 4**），按协议白名单特化；`promptCacheKey` + 亲和头；**服务端命中率/TTL = `UNOBSERVABLE`**（`ocv2-cache-01`）。

## 4. "默认" vs "开配置/装插件以后"（分列）

> 扩展点：会话钩子 `SessionHooks`（`packages/plugin/src/effect/session.ts`）+ 工具钩子 + `opencode.json`。**默认分发（未改配置、未装插件）不含下列"条件/插件"态行为。**

| 维度 | 默认（v2 本体） | 条件/配置/插件态能改什么 | 证据 |
|---|---|---|---|
| 自动压缩 | `compaction.auto = true`（默认开） | 设 `false` 后溢出不再自动压缩（转报错/手动） | `ocv2-compact-01`、`ocv2-trigger-02` |
| 触发预留 | `max(10%W, 16000)` | `compaction.buffer` 显式设值 → `window − buffer` | `ocv2-trigger-01` |
| 工具输出裁剪 | `ToolOutput` 默认 `maxLines=2000`/`maxBytes=51200` | `ToolOutput.configure({maxLines,maxBytes})` | `ocv2-trunc-01` |
| 保留预算 | `keep = 15000`（固定） | `compaction.keep.tokens`（v1 名 `preserve_recent_tokens` 迁移） | `ocv2-summary-02` |
| 压缩提示词 | 内置模板 + `compaction` agent 提示词 + 模板校验 | `session.compaction` 钩子可**整体替换**摘要（`fromHook` 跳过模型） | `ocv2-summary-01`、`ocv2-ext-01` |
| 压缩前裁剪 | **未见 `prune`**（v2 标 unsupported） | —（旧文档仍写 `prune`，**未同步**） | `ocv2-summary-03` |
| 请求消息/系统 | 指令源合成 + 投影消息 | `session.context` 钩子改 `system`/`messages`/`tools`（如按模型换系统提示词） | `ocv2-assembly-01`、`ocv2-ext-01` |
| 子 Agent | 内置 `subagent` 工具，深度上限 1，前台/后台 | `experimental.subagent_depth` 可增 | `ocv2-cm09-01` |
| 长期记忆 | **无**（推断） | 未见 v2 内置记忆开关 | `ocv2-memory-01` |
| 原生压缩 | 条件：`model.compaction.type==="native"` | 由模型元数据决定；须稳定且兼容的 endpoint | `ocv2-compact-04` |
| 缓存 | `cache:"auto"`（末工具 + 首/末 system + 尾 1） | 请求可传 `cache` 策略（`"none"`/对象）；协议白名单外不注标记 | `ocv2-cache-01` |

**一句话边界**：v2 的"默认"是**中等内核**——含子代理、自动压缩、崩溃恢复、插件钩子、原生压缩通道；**不含长期记忆、不含 `prune`**；`buffer`、`keep.tokens`、`subagent_depth`、原生压缩为**配置/条件态**，报告必须分列。
