这次改写不再使用作者的 Java 背景。阅读时可以亲手尝试：

1. 切换“压缩前、压缩后、重新打开、找回要求”，观察记录与当前材料的区别。
2. 改变“整理时是否保留返校时间”，对比两种结果。
3. 点击“存着、能取回、当前有”三张卡片，再完成三道即时反馈题。
4. 展开证据，查看每个关键结论的官方源码。

**核心意思：记录还在，不等于这次看见；重新打开，不等于全部重读。**
